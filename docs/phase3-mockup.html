Phase 3 Changes

1. Floating Pill Controls

Zoom, fit-view, auto-layout, and minimap toggle consolidated into a centered floating pill bar with backdrop blur. Replaces the stacked vertical button strip.

Before: Stacked buttons in bottom-left corner
After: Centered glass-morphism pill with tooltips

2. Arrow Markers on Edges

Every connection edge ends with a directional arrowhead, making data flow direction immediately clear. Condition edges use colored arrows (green Yes, red No).

Before: Plain lines with no direction indicator
After: SVG marker arrows at edge endpoints

3. Minimap Toggle

Minimap is no longer always visible — a dedicated toggle button in the pill bar shows/hides it with a smooth slide animation. Saves canvas space on smaller screens.

Before: Always-visible, no way to dismiss
After: Toggle with slide-in/out transition
