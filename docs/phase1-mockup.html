Phase 1 Changes Applied

  • SVG icons replace emojis (▶️→Play, 🔗→Webhook, ⏱️→Clock) in colored badge containers
  • Typography increased: titles from 0.78rem → 0.875rem (14px), body from 0.65rem → 0.75rem
  • Category background tints: subtle gradient per type (green=trigger, indigo=action, amber=flow, red=terminal)
  • Enhanced shadows: deeper box-shadow for more depth and layering
  • Node width increased: min-width from 180px → 200px, more breathing room
  • Consistent padding: 12px 16px inside nodes (was 8px 10px)
  • Sub-labels added: each node shows its category type below the title
  • Border radius: 10px → 12px for softer, modern feel
  • Dot-grid canvas: subtle grid pattern on background for spatial reference
  • Hover lift effect: nodes lift slightly on hover with enhanced shadow
