1. What Is API Key Authentication?

API key authentication sends a named key-value pair with the request — either as a custom HTTP header or as a URL query parameter. Unlike Bearer tokens, API keys use any header name the API expects.

Two Placement Modes

ModeWhereExample
Header Custom HTTP header X-API-Key: abc123def456
Query URL query parameter ?api_key=abc123def456

Common API Key Header Names

  • X-API-Key — Most common convention
  • X-Api-Key — AWS API Gateway default
  • api-key — Azure Cognitive Services
  • Authorization — Some APIs use ApiKey <value> format
  • x-functions-key — Azure Functions

2. The AuthConfig Data Model

// AuthConfig for API Key
{
  type: 'apikey',
  apiKeyName: 'X-API-Key',       // The header name or query param name
  apiKeyValue: 'abc123def456',   // The key value
  apiKeyIn: 'header'             // 'header' or 'query'
}

How resolveAuthHeaders Works for API Key

function resolveAuthHeaders(auth: AuthConfig): Record<string, string> {
  if (auth.type === 'apikey' && auth.apiKeyIn === 'header') {
    return { [auth.apiKeyName!]: auth.apiKeyValue! };
  }
  // query-param keys are handled in buildUrl(), not in headers
  return {};
}

How buildUrl Handles Query-Param Keys

function buildUrl(baseUrl: string, path: string, auth: AuthConfig): string {
  const url = new URL(path, baseUrl);
  if (auth.type === 'apikey' && auth.apiKeyIn === 'query') {
    url.searchParams.set(auth.apiKeyName!, auth.apiKeyValue!);
  }
  return url.toString();
}

UI State Mapping

// EnvAuthState (form fields)
{
  authType: 'apikey',
  apiKeyName: 'X-API-Key',       // maps to AuthConfig.apiKeyName
  apiKeyValue: 'abc123def456',   // maps to AuthConfig.apiKeyValue
  apiKeyIn: 'header',            // maps to AuthConfig.apiKeyIn
}

3. Configuring API Key Auth

Step 1: Open the Auth Tab

  1. Open the test in the Test Editor → Auth tab.
  2. Select API Key from the Type dropdown.

Step 2: Configure the Key

FieldDescriptionExample
Key NameThe header name or query param nameX-API-Key
Key ValueThe API key stringabc123def456
Add ToWhere to send the keyHeader or Query Params

Step 3: Verify

Click Verify to validate that key name and value are both non-empty.

💡 Header vs Query — Which to Choose? Prefer header placement. Query-param keys appear in server logs, browser history, and CDN caches. Headers are more secure and don't pollute the URL. Only use query params when the API explicitly requires it.

4. Walkthrough: Header-Based API Key

Using req-echo-headers

Load the gallery sample: Gallery → Requests → "Echo Headers & Body".

Step 1: Configure

  • Method: GET
  • URL: https://httpbin.org/headers
  • Auth Type: API Key
  • Key Name: X-API-Key
  • Key Value: my-secret-key-123
  • Add To: Header

Step 2: Run and Inspect

HTTPBin echoes back all received headers:

{
  "headers": {
    "Accept": "*/*",
    "Host": "httpbin.org",
    "X-Api-Key": "my-secret-key-123",
    ...
  }
}

Console Output

> GET https://httpbin.org/headers
> X-API-Key: my-secret-key-123
< 200 OK (112ms)

5. Walkthrough: Query-Param API Key

Step 1: Configure

  • Method: GET
  • URL: https://httpbin.org/get
  • Auth Type: API Key
  • Key Name: api_key
  • Key Value: my-query-key-456
  • Add To: Query Params

Step 2: Run and Inspect

The key appears in the URL and is echoed in the response:

{
  "args": {
    "api_key": "my-query-key-456"
  },
  "url": "https://httpbin.org/get?api_key=my-query-key-456"
}

Console Output

> GET https://httpbin.org/get?api_key=my-query-key-456
< 200 OK (98ms)
⚠ Query Params Are Visible Notice the key appears in the full URL. This URL may be logged by proxies, CDN edge nodes, and browser dev tools. For sensitive keys, always use header placement.

7. Exercises

Exercise 1: Header API Key

Goal: Send an API key as a custom header and verify it arrives.

  1. Create a test: GET https://httpbin.org/headers.
  2. Set API Key auth: name X-Custom-Key, value test123, in Header.
  3. Run and verify X-Custom-Key: test123 appears in the response headers echo.

Exercise 2: Query Param API Key

Goal: Send an API key as a query parameter.

  1. Create a test: GET https://httpbin.org/get.
  2. Set API Key auth: name access_key, value mykey789, in Query Params.
  3. Run and verify access_key=mykey789 appears in the response args and url fields.

Exercise 3: Variable-Based API Key

Goal: Use environment variables for the key value.

  1. Add an environment variable: myApiKey = secret-from-env.
  2. Create a test to https://httpbin.org/headers with API Key auth.
  3. Set key value to {{myApiKey}}.
  4. Run and verify the resolved value appears in the echoed headers.
