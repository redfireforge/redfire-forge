1. What Is the Data Mapper?

The Data Mapper is a visual tool for connecting source data fields to target fields. Instead of writing JSON paths and template expressions by hand, you drag and drop fields between two tree panels to create mappings.

ConceptDescription
Source Panel (left)Shows the structure of incoming data — API response body, headers, status code, or upstream workflow variables
Target Panel (right)Shows the expected structure of the output — the next request's body, validation target, or downstream variable shape
Canvas (middle)Displays connection lines between mapped fields, with badges showing the mapping type (direct, expression, loop, aggregate)
MappingA single connection from a source field to a target field, optionally with a transformation expression
💡 When to use the Data Mapper Use the mapper any time you need to extract values from one JSON shape and place them into another. Common places: request body builders, extraction rules, workflow variable assignments, and validation targets.

2. Opening the Data Mapper

The Data Mapper can be opened from several places in RedfireForge:

ContextHow to OpenWhat Appears
Request Body BuilderClick Open Mapper button in the body editor toolbarSource = previous response / extracted variables. Target = this request's body schema.
Extraction RulesClick Map Fields in the extraction editorSource = response body tree. Target = extraction variable definitions.
Workflow Node ConfigDouble-click a node → click Open Mapper in the node config modalSource = upstream node variables (grouped by origin). Target = this node's input fields.
Validation / AssertionsClick Map Expected in the assertion builderSource = actual response tree. Target = expected value template.

3. Understanding the Panels

3.1 Source Panel

The source panel shows a tree view of available data. Each node displays:

  • Field name — the JSON key
  • Type badge — str, num, bool, arr, obj
  • Sample value — the actual value from a fetched or pasted sample (shown in muted text)
  • Drag handle ⠿ — appears on hover; grab to start dragging

Loading Source Data

MethodWhen to Use
Fetch Sample ☁Click to execute the upstream request and populate the source tree with a live response. Best for accuracy.
Paste JSON 📋Paste or type a JSON sample manually. Use when offline or when you have a specific sample.

3.2 Source Tabs

When the source is an HTTP response, three tabs are available:

  • Body — the parsed JSON response body (most common)
  • Headers — response headers as key-value pairs
  • Status — status code and status text

3.3 Target Panel

The target panel shows the expected output structure. Mapped fields show a green left border and a source reference badge. Unmapped fields show a gray dash.

4. Creating Your First Mapping

1

Open the Mapper

From a request body builder or extraction editor, click Open Mapper.

2

Load Source Data

Click ☁ Fetch to execute the upstream request and populate the source tree. Or click 📋 Paste and paste a JSON sample.

3

Expand the Trees

Click the ▶ chevrons to expand both source and target trees. Find the fields you want to connect.

4

Drag and Drop

Hover over a source field to reveal the drag handle ⠿. Drag it to the matching target field and release. A green connection line appears on the canvas.

5

Check the Preview

The target panel shows the mapped value next to each field: ← source.path. The footer shows the mapping count.

6

Apply

Click ✓ Apply to save the mappings and close the mapper. The generated expressions are injected into the parent editor.

5. Auto-Map

Click the ✨ Auto-map button in the toolbar to automatically match source and target fields by name. The mapper uses exact name matching and common naming conventions (e.g., firstName ↔ first_name).

ℹ️ Auto-map is a starting point Auto-map connects fields it is confident about. Review the suggestions, remove incorrect ones, and manually map the rest. Fields with ambiguous matches are left unmapped for you to decide.

6. Removing a Mapping

To remove a mapping, hover over the connection line on the canvas and click the ✕ button that appears. Alternatively, click a mapped target field and press Delete or Backspace.

7. Searching Fields

Both source and target panels have a search box. Type a field name to filter the tree and highlight matches. Use / to focus the source search, Shift+/ for the target search.

8. Keyboard Shortcuts
