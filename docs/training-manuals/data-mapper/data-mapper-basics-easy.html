Data Mapper Basics

EASY   Sample: dm-extraction-mapping

A hands-on walkthrough using the Extraction Mapping sample. You will open a test scenario, launch the Visual Mapper, see source/target trees with real data, and verify extraction mappings visually.

Prerequisites Import the dm-extraction-mapping sample from the Gallery before starting. Go to Gallery → Data Mapper → "Extraction Mapping" → click Load Sample.

Part 1 — Open the Sample

1
Navigate to Scenarios

After importing, you'll be taken to the Scenarios tab. Find the group named Gallery: Data Mapper — Extraction.

2
Open the first test

Click on GET user → extract id, name, email, company to open the test editor.

You should see: The test editor with URL https://jsonplaceholder.typicode.com/users/1 and method GET.
3
Go to the Extract tab

Click the Extract tab (it shows a green badge with "6" indicating 5 extractions are defined).

You should see: A table with 5 extraction rows: userId → $.id, userName → $.name, userEmail → $.email, companyName → $.company.name, city → $.address.city.

Part 2 — Launch the Visual Mapper

4
Click "⚡ Visual Mapper"

Click the purple ⚡ Visual Mapper button at the top of the Extract tab.

You should see: The Data Mapper modal opens with title "Response Body → Variables".
5
Inspect the Source panel (left)

The Source panel shows the embedded API response as a JSON tree:

{
  "id": 1,
  "name": "Leanne Graham",
  "email": "Sincere@april.biz",
  "address": {
    "city": "Gwenborough",
    ...
  },
  "company": {
    "name": "Romaguera-Crona",
    ...
  }
}
You should see: A fully populated source tree with expandable nodes for address, company, and geo. Each leaf node shows the actual value (e.g., id: 1, name: "Leanne Graham").
6
Inspect the Target panel (right)

The Target panel shows the 5 extracted variable names:

Variable NameMapped From (Expression)
userId$.id
userName$.name
userEmail$.email
companyName$.company.name
city$.address.city
You should see: The Target panel with "5 mapped" badge and all 5 variable names listed. Each shows a purple connection line back to its source path.

Part 3 — Interact with the Mapper

7
Try Auto-Map

Click the Auto-map button in the toolbar. Since all fields are already mapped, it will show "6 mappings" (no change).

8
Search for a field

Type email in the Source search bar. The tree filters to show only email. Clear the search to restore the full tree.

9
Click Preview

Click the Preview button in the toolbar. This shows a live preview of what each extraction would produce:

VariablePreviewed Value
userId1
userName"Leanne Graham"
userEmail"Sincere@april.biz"
companyName"Romaguera-Crona"
city"Gwenborough"
You should see: Each target field shows the resolved value from the source JSON next to it.
10
Click Done

Click Done to close the mapper and save any changes back to the Extract tab.

Part 4 — Verify the Chain

11
Open the second test

Go back to the scenario list and open GET posts by extracted userId.

You should see: URL contains ?userId={{userId}} — the variable extracted from the first test will be substituted at runtime.
12
Open its Visual Mapper

Go to the Extract tab and open the Visual Mapper. The source shows a sample posts array response. The target shows firstPostId and firstPostTitle.
