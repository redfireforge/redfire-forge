2. Array → Array: The Loop Pattern

This is the most common array mapping. You have a source array and need to transform each element into a different shape.

Example: Orders → Line Items

// Source
{
  "orders": [
    { "orderId": 1001, "product": "Widget A", "quantity": 5, "unitPrice": 29.99 },
    { "orderId": 1002, "product": "Gadget B", "quantity": 2, "unitPrice": 49.99 }
  ]
}
↓ map each element ↓
// Target
{
  "lineItems": [
    { "sku": "Widget A", "qty": 5, "total": 149.95 },
    { "sku": "Gadget B", "qty": 2, "total": 99.98 }
  ]
}

2.1 Creating a Loop Mapping

  1. Drag the source array node (orders) onto the target array node (lineItems).
  2. A pink ∞ for each order badge appears on the connection line, indicating iteration.
  3. Both arrays auto-expand to show their child elements as [each].
  4. Now drag inner fields: product → sku, quantity → qty.
  5. For the computed total, click ƒx on total and type: item.quantity * item.unitPrice.
💡 Loop variable naming Inside a loop, the current element is referenced as item by default. You can rename it by clicking the loop badge and editing the variable name (e.g., order instead of item).

2.2 Accessing the Index

Inside a loop, $index gives the current zero-based position:

// Add a sequential line number
item.lineNumber = $index + 1

4. Filtered Arrays

To map only a subset of array elements:

  1. Create a loop mapping (source array → target array).
  2. Click the filter icon ⧩ on the connection line.
  3. The filter builder opens with field, operator, and value inputs.
  4. Set condition, e.g., item.status === "shipped".
// Generated expression
source.orders.filter(item => item.status === "shipped")
              .map(item => ({ sku: item.product, qty: item.quantity }))

5. Nested Arrays: Flatten & Collect

5.1 Flattening

When the source has nested arrays (array of arrays) and the target expects a flat array:

Flatten Example

// Source: departments[].employees[]
{
  "departments": [
    { "name": "Eng", "employees": [{"name":"Alice"}, {"name":"Bob"}] },
    { "name": "Sales", "employees": [{"name":"Carol"}] }
  ]
}
↓ flatten ↓
// Target: allEmployees[]
{
  "allEmployees": [
    {"name":"Alice"}, {"name":"Bob"}, {"name":"Carol"}
  ]
}

Drag the nested employees array onto the flat allEmployees target. A ⊏ flatten badge appears.

5.2 Collecting with Context

When flattening, you often need to carry parent context. The mapper supports this with the carry fields option on the flatten badge:

// Flatten but include department name
source.departments.flatMap(dept =>
  dept.employees.map(emp => ({
    ...emp,
    department: dept.name
  }))
)

Click the flatten badge → "Carry parent fields" → select department.name.

6. Grouping

The $groupBy function transforms a flat array into groups:

// Group orders by status
$groupBy(source.orders, "status")

// Result:
// { "shipped": [{...}, {...}], "pending": [{...}] }
FunctionDescription
$groupBy(arr, key)Group elements by a field value → object of arrays
$countBy(arr, key)Count elements per group → object of numbers
$keyBy(arr, key)Index array by unique key → object of elements
$chunk(arr, size)Split array into equal-sized groups
