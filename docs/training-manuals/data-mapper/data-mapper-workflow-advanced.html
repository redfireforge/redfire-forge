Full Combo — Extract + Validate + Body

ADVANCED   Sample: dm-combo-mapper

This walkthrough demonstrates all three Data Mapper surfaces in a single scenario: Extraction Validation Body Builder

Prerequisites Import the dm-combo-mapper sample from Gallery → Data Mapper → "Full Combo — Extract + Validate + Body" → Load Sample.

Request 1 — GET Products (Extract + Validate)

1
Open "GET products → extract & validate fields"

URL: https://dummyjson.com/products?limit=5

This request does two things at once: extracts 4 variables AND selectively validates 2 fields.

2
Check the Extract tab

Extraction Open the Extract tab. You'll see 4 extractions from the products array:

VariableExpressionValue from sample
totalProducts$.total194
firstProductId$.products[0].id1
firstProductName$.products[0].title"Essence Mascara Lash Princess"
firstProductPrice$.products[0].price9.99

Click ⚡ Visual Mapper to see the source tree with a products array of 5 items and the 4 mapped target variables.

3
Check the Validation tab

Validation Open the Validation tab. It's in Selective Mode (Include) with 2 expected fields:

JSON PathExpected Value
$.limit5
$.skip0

Click ⚡ Visual Mapper here too — the same source data appears, but the target shows the 2 validation fields instead of extraction variables.

Request 2 — Search Products (Uses extracted variable)

4
Open "GET product search using extracted name"

URL: https://dummyjson.com/products/search?q={{firstProductName}}

Key point: The search query q= uses {{firstProductName}} — the value "Essence Mascara Lash Princess" extracted from Request 1.

Request 3 — POST Product (Body template with mapped variables)

5
Open "POST add product with mapped body"

Body Builder This request uses extracted variables in a POST body:

{
  "title": "Copy of {{firstProductName}}",
  "price": "{{firstProductPrice}}",
  "description": "Cloned from product #{{firstProductId}}",
  "category": "test"
}

At runtime, this becomes:

{
  "title": "Copy of Essence Mascara Lash Princess",
  "price": "9.99",
  "description": "Cloned from product #1",
  "category": "test"
}

Run the Full Scenario

6
Execute and verify

Run the scenario from the Runner tab. All 3 requests execute in sequence:

  1. GET products → extracts 4 variables, validates 2 fields
  2. GET search → uses {{firstProductName}} in query
  3. POST add → sends body with all 3 extracted variables substituted
You should see: All 3 requests pass. The Results tab shows extracted variable values and validation results for each step.
