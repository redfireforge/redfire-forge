1. Beyond Direct Mapping

A direct mapping copies a source value as-is to the target. But many real-world scenarios require transformations: combining fields, converting types, formatting dates, or applying conditional logic. The Data Mapper supports these through expressions and the function palette.

2. The Expression Editor

Every target field has a ƒx button that appears on hover. Clicking it opens the inline expression editor.

2.1 Writing Expressions

Expressions use a JavaScript-like syntax with access to all source fields via source.* notation:

// String concatenation
source.firstName + " " + source.lastName

// Arithmetic
source.price * source.quantity

// Ternary conditional
source.status === "active" ? "ENABLED" : "DISABLED"
💡 Autocomplete As you type source., the expression editor shows a dropdown of available source fields with their types and sample values. Press Tab to accept a suggestion.

2.2 Live Preview

The expression editor shows a live preview of the result below the input. As you type, the expression is evaluated against the sample data and the result updates in real time.

Preview StateMeaning
Green check + valueExpression is valid and produced a result
Red ⚠ ErrorSyntax error or runtime error — check the message

4. Conditional Logic

4.1 If-Else

$if(source.status === "active", "ENABLED", "DISABLED")

The $if(condition, trueValue, falseValue) function evaluates the condition and returns one of two values.

4.2 Switch / Case

$switch(source.type, {
  "A": "Alpha",
  "B": "Beta",
  "C": "Gamma"
}, "Unknown")

The $switch(value, cases, default) function maps a value to one of several results, with a default fallback.

4.3 Coalesce (Null Fallback)

$coalesce(source.mobile, source.home, source.work, "N/A")

Returns the first non-null, non-undefined value from the argument list. Essential for handling optional fields.

5. Combining Multiple Sources

When a target field needs data from multiple source fields, drag the first source to the target, then drag the second source to the same target. A combine mode picker appears:

6. Splitting One Source to Many Targets

Drag a single source field to multiple target fields. Each mapping gets its own expression:

// Source: source.fullName = "John Michael Doe"
target.first  = source.fullName.split(" ")[0]   // "John"
target.middle = source.fullName.split(" ")[1]   // "Michael"
target.last   = source.fullName.split(" ")[2]   // "Doe"

7. Null Handling Patterns

PatternHow
Default value if null$coalesce(source.phone, "N/A")

⚠ Common Pitfall Expressions like source.user.name will throw an error if source.user is null. Use $get(source, "user.name") or source.user?.name for safe navigation.

8. Function Chaining

Functions can be nested or chained for multi-step transforms:

// Trim, then uppercase
$uppercase($trim(source.name))

// Parse date, then format
$dateFormat($dateParse(source.created, "MM/DD/YYYY"), "YYYY-MM-DD")

// Coalesce, then truncate
$truncate($coalesce(source.bio, "No bio"), 100)
💡 Visual Function Chain For complex multi-step transforms, you can also chain functions visually on the canvas. Each function appears as a small card on the connection line, showing its name and parameters. Click any card to edit its settings.

9. Practice Exercises

  1. Map a user API response where first_name and last_name must be combined into a single displayName target field.
  2. Map a product response where the string "29.99" must become the number 29.99 using the appropriate type conversion.
  3. Create a conditional mapping where status → isActive (boolean), treating "active" and "enabled" as true, everything else as false.
  4. Handle a nullable phone field with a cascade: try mobile, then home, then "N/A".
