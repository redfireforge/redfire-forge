Body Builder & Expression Mapping

MEDIUM   Sample: dm-body-builder

Learn how extracted variables are used to build a POST request body with {{variable}} templates. This walkthrough uses the Body Builder sample.

Prerequisites Import the dm-body-builder sample from Gallery → Data Mapper → "Body Builder Mapping" → Load Sample.

Part 1 — Understand the Extraction Step

1
Open the first test

Navigate to Scenarios → Gallery: Data Mapper — Body Builder → GET user → extract fields for next request.

2
Review the Extract tab

Click Extract. You'll see 6 extractions that pull fields from the user response:

VariableExpressionPreviewed Value
userId$.id1
userName$.name"Leanne Graham"
userEmail$.email"Sincere@april.biz"
userPhone$.phone"1-770-736-8031 x56442"
companyName$.company.name"Romaguera-Crona"
companyCatchPhrase$.company.catchPhrase"Multi-layered client-server neural-net"
3
Open Visual Mapper to verify

Click ⚡ Visual Mapper. The source tree shows the full user JSON. The target shows all 6 variable names with mapping lines.

You should see: Source panel populated with user data (name: "Leanne Graham", company.name: "Romaguera-Crona", etc.) and 6 mapped target variables.

Part 2 — Inspect the Body Template

4
Open the second test (POST)

Go back and open POST /posts with mapped body template.

5
Look at the Body tab

The request body contains {{variable}} placeholders that will be replaced with extracted values at runtime:

{
  "userId": "{{userId}}",
  "title": "Post by {{userName}}",
  "body": "Contact: {{userEmail}} / {{userPhone}}. Company: {{companyName}} — {{companyCatchPhrase}}"
}
You should see: The body editor highlighting {{...}} placeholders in a distinct color. Each corresponds to a variable extracted in the previous step.

Part 3 — Run and Verify

6
Run the scenario

Go to the Runner tab, select this scenario, and run it. The first request fetches the user, extracts variables, and the second request sends the POST with the substituted body.

7
Check the result

After execution, open the second test's result. The sent body should contain the actual values:

{
  "userId": "1",
  "title": "Post by Leanne Graham",
  "body": "Contact: Sincere@april.biz / 1-770-736-8031 x56442. Company: Romaguera-Crona — Multi-layered client-server neural-net"
}
