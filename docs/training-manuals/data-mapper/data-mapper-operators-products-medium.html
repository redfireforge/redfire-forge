Validation Operators — Products

MEDIUM   Sample: dm-validation-operators

Walk through all 24 field operators using real product data from DummyJSON (dummyjson.com/products). Every operator category is demonstrated with live data you can verify immediately.

Prerequisites Import the dm-validation-operators sample from Gallery → Data Mapper. This gives you a pre-configured test hitting https://dummyjson.com/products?limit=3 with 13 validation rules across all 7 operator categories.

Part 1 — Import & Open

1
Import the sample

Go to Gallery → Data Mapper → Validation Operators Showcase. Click Import. A new Feature Group named "Data Mapper — Validation Operators" appears in your test list.

2
Open the test editor

Expand the Feature Group → Product Operators Showcase → click GET products → validate with operators. The test editor opens.

3
Open Data Mapper

Go to the Validation tab. The mode is set to Selective Fields. Click Data Mapper to open the visual mapper. The Source panel shows the DummyJSON response; the Target panel shows 13 mapped fields with operator pills.

You should see: Source tree with products array, total, skip, limit. Target tree with color-coded operator pills: green (equals), amber (greater_than, between), purple (contains, starts_with, regex), gray (exists, is_not_empty), teal (is_type), blue (in).

Part 2 — Equality Operators (Green)

4
equals — exact match

Find the $.products[0].category target node. Its pill shows equals (green) with value "beauty".

This asserts the first product's category is exactly "beauty". The DummyJSON /products?limit=3 endpoint returns beauty products, so this passes.

Try it: Click Verify All. The category node shows ✓ (pass). Change the value to "electronics" and verify again — it shows ✗ (fail).
5
not_equals — negative match

Find $.products[0].availabilityStatus. Its pill shows not_equals with value "Discontinued".

This asserts the product status is anything except "Discontinued". Since it's "Low Stock", it passes.

Part 3 — Comparison Operators (Amber)

6
greater_than — numeric guard

Find $.products[0].price with greater_than > 0. The product price is 9.99, so this passes.

Also check $.total with greater_than > 100. DummyJSON has 194 total products.

7
between — range check

Find $.products[0].rating with between 1, 5. This asserts the rating is between 1 and 5 (inclusive). The rating is 4.94 — passes.

Try it: Click the pill, change to 4.9, 5.0 — still passes. Change to 5.0, 5.5 — fails because 4.94 < 5.0.
8
greater_than_or_equal

Find $.products[0].stock with greater_than_or_equal ≥ 0. Stock is 5 — passes. This is useful for "non-negative" checks.

Part 4 — String Operators (Purple)

9
contains — substring

Find $.products[0].title with contains "Mascara". The title is "Essence Mascara Lash Princess" — contains "Mascara", passes.

10
starts_with — prefix

Find $.products[0].brand with starts_with "Ess". Brand is "Essence" — starts with "Ess", passes.

11
regex — pattern match

Find $.products[0].sku with regex ^[A-Z0-9]+$. The SKU is "RCH45Q1A" — all uppercase letters and digits, passes.

Try it: Change the pattern to ^[a-z]+$ (lowercase only) — fails because SKU has uppercase.

Part 5 — Existence, Type & Set Operators

12
exists and is_not_empty (Gray)

Find $.products[0].meta with exists — asserts the path is present (even if null). Find $.products[0].tags with is_not_empty — asserts the tags array has at least one element.

13
is_type (Teal)

Find $.products[0].price (second mapping) with is_type number. This asserts the price is a JavaScript number type. Since 9.99 is a number, it passes.

Tip Available types: string, number, boolean, object, array, null.
14
in — set membership (Blue)

Find $.products[0].category (second mapping) with in beauty, electronics, furniture. This asserts the category is one of the listed values. "beauty" is in the set — passes.

Try it: Remove "beauty" from the set, leaving only "electronics, furniture" — the assertion fails.

Part 6 — Verify All

15
Run verification

Click Verify All in the toolbar. All 13 rules should pass with green ✓ badges on each target node.

Open the Mapping View (bottom section) and switch to Table view. The Status column shows "✓ pass" for every row.

You should see: 13/13 passed. Canvas lines are all green. Toolbar shows aggregated pass count.
