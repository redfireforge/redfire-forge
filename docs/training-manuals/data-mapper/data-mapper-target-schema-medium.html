Validation Mapping (Selective Mode)

MEDIUM   Sample: dm-validation-mapping

Learn how to validate specific response fields using the Data Mapper's Selective Validation mode. Instead of checking every field, you pick exactly which fields to assert on.

Prerequisites Import the dm-validation-mapping sample from Gallery → Data Mapper → "Validation Mapping" → Load Sample.

Part 1 — Understand the Test

1
Open the test

Navigate to Scenarios → Gallery: Data Mapper — Validation → GET product/1 → validate name, price, category.

URL: https://dummyjson.com/products/1

2
Go to the Validation tab

Click the Validation tab. You'll see it's in Selective Mode (Include) — only the listed fields are validated.

You should see: 5 expected fields listed in a table:
JSON PathExpected Value
$.titleEssence Mascara Lash Princess
$.price9.99
$.categorybeauty
$.brandEssence
$.stock5

Part 2 — Open the Visual Mapper

3
Click "⚡ Visual Mapper" on the Validation tab

The Data Mapper opens in validation context.

4
Inspect the Source panel

The source shows the embedded product response — a rich JSON with nested objects:

{
  "id": 1,
  "title": "Essence Mascara Lash Princess",
  "description": "The Essence Mascara...",
  "category": "beauty",
  "price": 9.99,
  "stock": 5,
  "brand": "Essence",
  "dimensions": { "width": 23.17, "height": 14.43, "depth": 28.01 },
  "reviews": [ ... ],
  "meta": { "createdAt": "2024-05-23", ... },
  ...
}
You should see: A fully populated tree with ~25+ fields including nested dimensions, meta, and reviews arrays. Expand nodes to explore the full structure.
5
Inspect the Target panel

The target shows the 5 fields selected for validation, each with its expected value:

You should see: 5 target fields: title, price, category, brand, stock. Each shows a mapping line back to the corresponding source field and the expected value.

Part 3 — Modify Validation Rules

6
Add a new validation field

In the Target panel, try adding a new expected field. For example, drag rating from the source to the target, or click "Add Field" and type $.rating with expected value 4.94.

You should see: The target now shows 6 fields. The new field appears with a mapping line to the source.
7
Use Preview to verify

Click Preview. Each validation field shows the actual value from the source JSON next to the expected value, letting you verify they match.

8
Click Done

Click Done to save your changes back to the Validation tab. The expected fields table updates with your additions.
