What Is the Gallery?

The Gallery is the central sample browser in RedfireForge. It gives you instant access to dozens of pre-built, ready-to-run examples across every major feature area. Instead of building from scratch, open the Gallery, pick an entry, click one button, and begin working with a fully configured sample.

Open the Gallery from the top navigation bar by clicking the Gallery icon, or navigate directly to /?tab=gallery.

Two Gallery Tabs

TabWhat You SeeBest For
Samples (default) A filterable, searchable, paginated grid of sample cards — one card per gallery entry, across 9 domains Finding and importing a specific sample to start working
Training Tracks A full learning-progress dashboard: progress stats, Continue Learning card, What's New banner, and all training paths with per-manual status tracking (Not Started / Viewed / Completed) Following a structured curriculum, tracking progress, and resuming where you left off

Switch between tabs using the Samples / Training Tracks sub-nav at the top of the Gallery page.

Gallery Domains (9)

Every gallery entry belongs to one of nine domains. A domain identifies what kind of resource the entry creates when imported.

Gallery Card Anatomy

Each card in the grid shows:

  • Icon — visual identifier for the domain or entry type
  • Name — the sample's title
  • Description — one-line summary of what the sample demonstrates
  • Difficulty dots — filled circles: 1 dot = easy, 2 = medium, 3 = advanced
  • Domain badge — shows when viewing "All" domains so you can tell which domain the card belongs to
  • Tags — keyword chips (e.g. rest, pagination, auth)
  • Status badge — only appears after importing: ✓ Loaded or ↻ Reload (Updated)

Filter Sidebar

The sidebar on the left side of the gallery (resizable by dragging its right edge) provides five filters that combine to narrow the card grid:

FilterWhat It Filters By
Domain buttons10 buttons: All + each of the 9 domains. Clicking one shows only entries from that domain.
CategorySub-grouping within a domain (e.g. "CRUD", "Auth", "Streaming")
DifficultyAll / Easy / Medium / Advanced
Live APIFilter to entries that use a specific external API hostname
TagFilter to entries that carry a specific keyword tag

Detail Panel

Click any gallery card to open a detail panel on the right side. The panel provides:

  • Full name, description, difficulty, and tags
  • Live API badges — links showing which external APIs the sample calls (e.g. jsonplaceholder.typicode.com)
  • Primary action button — the domain-specific import action (e.g. "Load Workflow")
  • Secondary action button — "Try It" for Requests (sends without importing)
  • Preview area — request structure for Requests; truncated JSON payload for other domains; expand button for full text
  • Related Training Manuals — links to relevant HTML training manuals with difficulty dots
