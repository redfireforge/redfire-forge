Browsing the Gallery

Easy   Domain filters · Search · Cards · Detail panel · Preview · Related manuals

Overview

In Samples mode (the default), the Gallery is a filterable, searchable grid of pre-built entries. This manual walks through how to navigate domains, narrow results with filters, read a card, open the detail panel, and find the training manual for a sample.

Step-by-Step Walkthrough

1
Open the Gallery Click the Gallery icon in the top navigation bar. The gallery opens in Samples mode with all 9 domains visible — you should see many cards.
2
Filter by domain In the left sidebar, click one of the domain buttons (e.g. Tests 🧪). The grid immediately updates to show only entries from that domain. The active domain button is highlighted. Click All to return to the full view.
3
Search by keyword Type in the search bar at the top of the gallery (placeholder: "Search gallery…"). The grid filters in real time across name, description, tags, and category. Try searching for "pokemon" or "auth" to see it narrow immediately. Clear the field to reset.
4
Refine with sidebar filters Below the domain buttons in the sidebar are additional dropdowns:
  • Category — sub-groups within the selected domain (e.g. "CRUD", "Auth")
  • Difficulty — All / Easy / Medium / Advanced
  • Live API — filter to samples that call a specific external API hostname
  • Tag — filter by keyword tag
Drag the sidebar's right edge to resize it if needed.
5
Browse the card grid Cards are paginated — 12 per page by default. Use the ← Previous / Next → pagination controls at the bottom when there are more results than fit on one page. Each card shows: icon, name, description, difficulty dots, domain badge (in All view), and tags.
6
Click a card to open the detail panel Clicking any card opens the detail panel on the right. The panel stays open until you click a different card or click the ✕ close button (top-right of the panel). Clicking the same card again also closes it.
7
Read the detail panel The panel shows:
  • Full description and difficulty dots
  • Tags — keyword chips
  • Live API badges — each external API the sample calls, shown as a hostname chip. Useful for checking if a live internet connection is required.
  • Action buttons — primary (e.g. "Load Workflow") and, for Requests, a secondary "Try It" button
8
Inspect the preview Below the action buttons is a Preview area:
  • For Requests: a rich `RequestPreview` showing method, URL, headers, and response structure
  • For other domains: up to 800 characters of the raw JSON payload (the sample data itself)
When the preview is plain text, an Expand ↗ button opens a full-screen modal so you can read the whole content.
9
Find related training manuals At the bottom of the detail panel, the Training Manuals section (📖 header) lists HTML manuals linked to this sample. Each link shows the manual title and difficulty dots. Click a link to open the training manual PDF/HTML in a new tab — it provides step-by-step instructions for using this sample.

Pagination

When more than 12 entries match the current filter/search combination, the gallery paginates them 12 at a time. The pagination controls appear at the bottom of the card grid. Changing the domain filter or search query resets to page 1 automatically.

Smoke-Test Checklist

  1. Open Gallery — verify multiple cards are visible
  2. Click Workflows ⚡ domain button — verify only workflow cards show
  3. Type "pokemon" in search — verify cards related to Pokémon appear
  4. Clear search — verify all domain-filtered cards return
  5. Click a card — verify detail panel opens with name, description, difficulty, and action button
  6. Verify Live API badges appear for entries that call external APIs
  7. Verify the Training Manuals section appears (at least for Requests domain entries)
  8. Click Expand ↗ on a non-Requests card preview — verify full-screen modal opens
  9. Close detail panel with ✕ — verify panel disappears
