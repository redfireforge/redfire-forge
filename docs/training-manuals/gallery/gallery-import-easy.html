Importing Gallery Samples

Easy   Per-domain actions · Navigation after import · ✓ Loaded badge · ↻ Reload Updated modal · Workflow preview mode

Overview

Importing a gallery sample takes one click — but each domain has different import behaviour: different action labels, different tabs you land on, and different badge states. This manual covers the full import lifecycle for all nine domains.

Walkthrough: Importing a Test Sample

1
Filter to Tests Open the Gallery and click Tests 🧪 in the domain sidebar.
2
Choose a sample Browse or search the grid. Click a card — for example, "User API Smoke Test". The detail panel opens on the right.
3
Click "Load Test" Click the Load Test button in the detail panel. The app navigates to the Tests tab and the scenario is pre-selected and ready to run.
4
Return to gallery and see the ✓ badge Navigate back to the Gallery. The card for the sample you just imported now shows a ✓ Loaded badge in its top-right corner.

Walkthrough: Importing a Workflow Sample

Workflow imports have an extra step — a preview mode — to let you review the workflow before committing it to your workspace.

1
Click "Load Workflow" In the gallery, click a Workflows domain card → click Load Workflow. The app navigates to the Workflow tab and the workflow canvas shows the sample in preview mode — a blue wf-preview-banner appears at the top of the canvas.
2
Review the workflow canvas Explore the nodes and connections. You can see the workflow structure before committing.
3
Save or discard
  • Click "Use as Template" in the preview banner to save the workflow to your workspace. After saving, the gallery card shows ✓ Loaded.
  • Click "Close Preview" to discard — the workflow is not saved and no badge appears in the gallery.

The ✓ Loaded Badge

After a sample is imported (and for workflows, saved), its gallery card shows a green ✓ Loaded badge. This badge tells you the sample is already in your workspace at the current version.

Action on a ✓ Loaded CardResult
Click the card to open detail panel, then click the action buttonNavigates directly to the tab where the sample lives — no modal, no re-import
Sample has been updated by a newer versionBadge changes to ↻ Reload (Updated)

The ↻ Reload (Updated) Badge

When a gallery sample has been updated since you last imported it, the badge changes to ↻ Reload (Updated). Clicking the action button shows a "Update Available" confirmation modal:

  • "[Sample Name]" has been updated since you last imported it. Re-import with the latest version?
  • Click Update to replace with the new version
  • Click Cancel to keep your existing version
Updating replaces your current version Clicking Update re-imports the sample, overwriting what was there. If you have local modifications to an imported workflow or test, save a copy with a different name before updating.

The "From Template" Shortcut

The Workflow tab has a + New → From Template button that opens the gallery pre-filtered to the Workflows domain. This is equivalent to opening the Gallery and clicking the Workflows domain button — it's a shortcut for adding new workflow templates without leaving the workflow area.

Assertions domain — no navigation The Assertions domain's "Apply Preset" button is the one exception: it applies the preset directly to the active test without navigating away from the gallery. No badge is tracked for assertion presets.

Smoke-Test Checklist

  1. Open Gallery → Tests → click a card → click "Load Test" → verify Tests tab opens with the scenario selected
  2. Return to Gallery → verify the card now shows a ✓ Loaded badge
  3. Click the ✓ Loaded card action button → verify it navigates to the Tests tab (no modal)
  4. Open Gallery → Workflows → click a card → click "Load Workflow" → verify wf-preview-banner appears
  5. Click "Use as Template" → return to Gallery → verify ✓ Loaded badge appears on the workflow card
  6. Load the same workflow again → click "Close Preview" → return to Gallery → verify ✓ Loaded badge is gone (not persisted)
  7. Open Gallery → Requests → click a card → click "Try It" → verify request is sent without navigating to a different tab
