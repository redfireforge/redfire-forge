Gallery — Training Paths Mode

Medium   Switching modes · Path/phase/manual hierarchy · Search · Active path · Sample links

Overview

In addition to the sample grid, the Gallery has a Training Paths mode — a structured curriculum view that organises all training manuals into logical learning journeys. Instead of browsing individual samples, you follow a sequence of phases and manuals from beginner to advanced.

Samples mode vs. Training Paths mode
  • Samples mode — "I want to load a specific sample and get to work immediately"
  • Training Paths mode — "I want to learn a feature from scratch, following a guided curriculum"
Both modes are in the same gallery page — use the mode toggle to switch instantly.

Switching to Training Paths Mode

1
Open the Gallery Click the Gallery icon in the top navigation. The page opens in Samples mode (card grid).
2
Click "Training Paths" in the mode toggle At the top of the gallery, find the Samples / Training Paths toggle strip. Click Training Paths. The card grid is replaced by a vertical list of training path cards.
3
Read the header The view now shows a 📖 Training Paths heading with the subtitle: "Structured learning journeys. Click a path to see its phases, manuals, and linked samples."

The Path / Phase / Manual Hierarchy

Every item of training content is organised in three levels:

LevelWhat It IsExample
PathA complete learning journey covering one feature area"GraphQL Studio", "Webhook Delivery Logs", "Request Basics"
PhaseA group of related manuals within a path, representing a stage of learning"Getting Started", "Core Operations", "Advanced Topics"
ManualAn individual training HTML document covering a specific topic"Your First Query", "Schema Explorer", "Mutations"

In the Training Paths view, each path is displayed as a collapsible card. Clicking a path card expands it to reveal its phases and the manuals within each phase.

Step-by-Step Walkthrough

4
Browse the path list You will see all ~27 training paths listed. Each card shows: path name, icon, and a brief description. Scroll to see paths across all feature areas (Requests, Workflow, GraphQL, gRPC, WebSocket, SSE, Webhooks, etc.).
5
Click a path card to expand it Click any path card. It expands to show its phases (e.g. "Getting Started", "Core Operations"). Each phase header lists the phase name, and below it are the manuals in that phase.
6
Read a manual row Each manual row shows:
  • Manual title — e.g. "Your First Query"
  • Difficulty dots — how complex this manual is
  • Sample chip (if linked) — a clickable chip that navigates to the corresponding gallery sample in Samples mode
  • Manual link — opens the HTML training document in a new tab
7
Search within Training Paths The search bar above the path list filters across path names, descriptions, phase names, and manual titles simultaneously. Type "webhook" to find any path, phase, or manual mentioning webhooks. Clear the search to see all paths again.
8
Focus on a single path If you navigate to the gallery from a feature-specific link (e.g. from a "View Learning Path" button on a feature page), the gallery may open with a specific path already active. When a path is active:
  • Only that path's card is shown (all others hidden)
  • A ← All Training Paths back button appears at the top
  • Click it to return to the full list of all paths
9
Click a sample chip to jump to the sample If a manual row has a linked sample chip, clicking it switches the gallery back to Samples mode and scrolls to / highlights that specific sample card. This lets you move from "read the manual" to "load the sample" with one click.
10
Open a training manual Click the manual title link in any manual row. The HTML training document opens in a new browser tab, ready to follow along.

Switching Back to Samples Mode

Click Samples in the mode toggle at any time to return to the card grid. Any domain filter or search you had active before switching to Training Paths mode is preserved.

Smoke-Test Checklist

  1. Open Gallery → click Training Paths in the mode toggle → verify card grid disappears and path list appears
  2. Verify "📖 Training Paths" heading and subtitle are visible
  3. Click any path card → verify it expands to show phases and manuals
  4. Verify each manual row shows title + difficulty dots
  5. Type "graphql" in the search bar → verify only GraphQL-related paths/phases/manuals appear
  6. Clear search → verify all paths reappear
  7. If a manual has a sample chip, click it → verify gallery switches to Samples mode for that sample
  8. Click Samples in mode toggle → verify card grid returns
