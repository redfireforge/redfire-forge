Gallery — Training Tracks

Medium   Progress dashboard · Continue Learning · What's New · Search & filter · Mark complete

Overview

The Training Tracks tab (Gallery → Training Tracks) is a full learning-progress system. Unlike the Samples tab, Training Tracks is not about importing data — it is about following a structured curriculum, tracking which manuals you have read, and resuming where you left off.

Training Tracks vs. Gallery Samples
  • Samples tab — browse and import pre-built entries across 9 domains
  • Training Tracks tab — follow a guided curriculum, track progress, mark manuals as completed
Both live under the Gallery navigation item. Switch between them using the sub-nav tabs at the top of the Gallery page.

Opening Training Tracks

1
Click Gallery in the sidebar Click the Gallery icon in the left navigation. The Gallery page opens.
2
Click "Training Tracks" in the sub-nav At the top of the Gallery page, two tabs appear: Samples and Training Tracks. Click Training Tracks. The full training dashboard replaces the sample grid.

Walkthrough

3
Read the Progress Dashboard The stats bar at the top shows three numbers: how many manuals exist in total, how many you have opened (Viewed), and how many you have marked as Completed. These update automatically as you use the system.
4
Use "Continue Learning" If you have previously opened any manual, the Continue Learning card shows the last in-progress manual with its path name, phase name, difficulty dots, and an Open Manual button. Click it to reopen the manual in a new tab.
5
Check What's New The What's New banner lists manuals added in recent releases. Click any item to open it. Click Show more to expand the full list. The banner is hidden when the search filter is active.
6
Browse the Learning Paths list Below the banner you see all active training paths under the heading "Learning Paths — N paths available · N manuals total". Each path is a collapsible card. Click a card header to expand it and see its phases and manuals.
7
Read a manual Inside an expanded path card, find a manual row. Each row shows:
  • Manual title and difficulty dots
  • Status badge (Not Started / Viewed / Completed) — shown as a colored chip
  • Open Manual button — opens the HTML training document in a new browser tab, and automatically marks the manual as Viewed
  • → Sample chip — if the manual is linked to a gallery sample, this navigates to that sample in the Samples tab
8
Mark a manual as Completed After reading a manual, click its status chip and select Completed. The badge updates, and the Progress Dashboard's Completed count increments. You can also set status to Not Started to reset it.
9
Search and filter manuals Use the search bar to filter manuals by keyword (matches title, description, path name, phase name). Use the Difficulty dropdown (All / Easy / Medium / Advanced) and Status dropdown (All / Not Started / Viewed / Completed) to narrow down. When filters are active, the path list shows only matching manuals — and each matching path card is auto-expanded. Clear filters to return to the full list.

Manual Status Reference

StatusMeaningHow It Changes
Not StartedManual has never been openedDefault for all new manuals; you can reset to this manually
ViewedManual was opened at least onceSet automatically when you click "Open Manual"
CompletedYou have finished and marked the manual doneSet manually via the status chip after reading

Progress Persistence

Training progress is saved locally in the browser (local storage). It persists across page reloads and browser restarts on the same machine. Progress is not synced across devices or browsers.

Smoke-Test Checklist

  1. Click Gallery → click Training Tracks sub-nav tab → verify progress dashboard appears
  2. Verify "Learning Paths" section shows multiple path cards
  3. Click a path card → verify it expands to show phases and manuals
  4. Click Open Manual on any manual → verify it opens in a new tab and the status badge changes to "Viewed"
  5. Click the status chip on a Viewed manual → select Completed → verify badge updates and Progress Dashboard completed count increments
  6. Type a keyword in the search bar → verify only matching manuals appear (in auto-expanded path cards)
  7. Click → Sample chip on a manual that has a linked sample → verify gallery switches to Samples tab for that entry
  8. Click Samples sub-nav tab → verify you return to the sample grid
