Learning Paths

Guided routes through the nodes — start from Path 1 and work your way up.

1 Linear Flow
Your first workflow — sequential API calls with variable chaining.
Start→ HTTP→ Delay→ HTTP→ End
For: First-time users
2 Branching & Routing
Decision logic — route execution based on API responses or variable values.
Condition→ Switch→ SetVariable
For: Building conditional logic
3 Loops & Aggregation
Process lists of items and accumulate results across iterations.
Loop→ HTTP→ Aggregate→ SetVariable
For: Batch processing & data collection
4 Parallel Processing
Run multiple branches concurrently and merge results.
Fork→ HTTP ×N→ Join→ Aggregate
For: Performance & concurrent APIs
5 External Triggers
Start workflows from webhooks, schedules, or wait for external callbacks.
Webhook · Schedule · CorrelationWait
For: Event-driven & async patterns
6 Code & Transform
Custom JavaScript for data transformation, validation, and generation.
Script→ LogDebug
For: Custom logic & data shaping
7 Error Handling & Composition
Build resilient workflows with retry, fallback, and reusable sub-workflows.
ErrorHandler→ SubWorkflow→ WaitForCondition
For: Production-grade resilience
