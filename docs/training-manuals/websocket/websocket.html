WebSocket Studio

The complete guide to testing WebSocket APIs — from a first ws:// connection through protocol adapters, load testing, and workflow automation.

What is WebSocket Studio?

WebSocket Studio is the persistent-connection testing environment inside RedfireForge. Unlike REST clients that open a new connection per request, WebSocket Studio maintains a stateful, bidirectional channel. You can send and receive messages at any time, monitor a live stream of frames, record sessions, and replay them — all from a multi-tab interface that supports up to 8 simultaneous connections.

Interface Overview

Mode Switcher

The three buttons at the top of the pane switch the active connection into a different operating mode:

ModePurpose
Client (mode-client)Standard WebSocket client — connect to any server, send/receive messages
Mock (mode-mock)Start a built-in WebSocket server that responds to clients under rules you define
Saved (mode-saved)Browse and replay previously saved connection presets and session recordings

Left Panel Tabs

TabContents
ConnectURL field, protocol selector, TLS settings, connect/disconnect button, status badge
ParamsQuery-string parameters appended to the WebSocket URL at connection time
AuthAuthentication type (None, Bearer, API Key, Basic, Custom) — injected as headers on the HTTP upgrade request
HeadersCustom HTTP headers sent during the WebSocket upgrade handshake
SendMessage compose area, format selector (text/JSON/binary), Send button, STOMP/Socket.IO compose fields

Right Panel Tabs

TabContents
EventsLive message log — all sent and received frames with timestamps, size, direction arrow
ConsoleLifecycle log + command console for scripted send sequences
StatsReal-time metrics: messages/sec, bytes in/out, total frames, uptime
Load TestConcurrent connection launcher — configurable worker count, duration, and rate
SchemaJSON schema editor and message validator — infer from traffic or define manually

Multi-Tab Connections

WebSocket Studio maintains a tab bar (conn-tab-bar) that lets you open up to 8 independent connections simultaneously — each with its own URL, auth, headers, message log, and stats. Tabs can be renamed, reordered by drag-and-drop, and navigated with keyboard shortcuts.

Protocol Support

ProtocolUse CaseNotes
Plain WebSocketRaw ws:// / wss:// connectionsDefault mode
Socket.IOSocket.IO EIO4 event-based protocolRequires Socket.IO server; adds event envelope
STOMPMessaging protocol over WebSocket (RabbitMQ, ActiveMQ)Adds COMMAND/HEADER/BODY compose UI
GraphQL-WSGraphQL subscriptions over WebSocket (graphql-ws)Handles connection_init / subscribe framing
