gRPC: Collections & History

Medium   Save · Replay · Import · Export

What You Will Learn

  • Save a request to a collection and organise with folders
  • Replay a saved request in one click
  • Browse and replay calls from the execution history
  • Import a grpcurl CLI command into a collection
  • Export and share collections with team members

Collections vs History

FeatureCollectionsHistory
What it storesManually saved requests (named, organised)Auto-saved log of every call you made
OrganisationFolders, custom names, tagsChronological, auto-named by method
PersistencePermanent until deletedRolling window (last N calls)
Best forReproducible test scenariosQuickly re-run a recent call

Collections View

Opening Collections

1
In gRPC Studio, click the Collections tab in the sub-nav (or the folder icon in the top toolbar). The collections panel opens showing all saved request groups.

Saving a Request to a Collection

2
Make a call from the request composer (e.g., a unary Echo call with a specific payload). After the call completes, click Save to Collection (the bookmark icon near the request editor, or the context menu → Save).
3
A dialog appears asking for a name, optional folder, and optional description. Enter a meaningful name such as Echo — health ping.
4
To create a folder, type a new folder name in the folder field and press Enter. Click Save. The request appears in the collections panel under the chosen folder.

Replaying a Saved Request

5
In the collections panel, click any saved request row. The studio loads the target host, schema, method, and request body into the composer.
6
Click Send (or Start Stream for streaming methods). The call executes immediately using the restored parameters.

Editing a Saved Request

7
Hover a collection entry and click the ⋯ (more) menu. Choose Edit to rename, move to a different folder, or update the description.
8
After loading a saved request and modifying the body, click Save again to update the existing entry (overwrite), or Save as New to create a copy.

Deleting and Organising

9
Drag and drop request rows within the collections panel to reorder them. Drag a request onto a folder to move it.
10
To delete an entry or folder, open its ⋯ menu and click Delete. Deleting a folder deletes all requests inside it.

History View

Opening History

11
Click the History tab in the gRPC Studio sub-nav. The history panel lists all past calls in reverse-chronological order, grouped by date.

Replaying from History

12
Click any history entry to load its parameters into the composer. The entry shows the method name, target host, timestamp, and final status (OK / error code).
13
Click Send to replay the call. History entries are read-only — to save a history entry for reuse, click Save to Collection from within the history detail panel.

Copying a Call as cURL / grpcurl

14
From any history entry's ⋯ menu, click Copy as grpcurl. The equivalent grpcurl CLI command is copied to your clipboard:
grpcurl -plaintext -d '{"message":"Hello"}' \
  localhost:50051 echo.EchoService/Echo
15
This is useful for sharing calls with teammates who prefer the CLI, or for reproducing issues in a terminal.

Importing a grpcurl Command

If a colleague sends you a grpcurl command, you can paste it directly into gRPC Studio without manually filling in fields.

16
In the collections panel, click Import (or the upload icon). Choose Import from grpcurl.
17
Paste the full grpcurl command into the text area:
grpcurl -plaintext \
  -d '{"message":"imported-call","repeat_count":3}' \
  localhost:50051 echo.EchoService/Echo
18
Click Parse & Import. The studio extracts the target, method, flags, and body. A preview shows the parsed fields. Click Save to Collection to keep it, or Load to Composer to run it immediately.
💡 Supported grpcurl flags The parser understands common flags: -d (data), -plaintext, -insecure, -H (header), -authority, and -proto. Complex flags like -import-path are noted but not automatically applied.

Exporting Collections

19
In the collections panel, click ⋯ on a folder or the root collection and choose Export. The studio downloads a JSON file containing all requests in that folder, preserving names and folder structure.
20
To import a shared collection, click Import → Import JSON and select the file. Imported entries are added to the existing collection without overwriting.

Practice Exercises

  1. Save three different unary calls to a folder called Echo Tests. Replay each one and confirm the correct payloads are loaded.
  2. Find the most recent call in History and save it to a new collection entry.
  3. Copy a call as grpcurl, paste it into the grpcurl import dialog, and run it from there.
  4. Export your Echo Tests folder as JSON, then delete the folder and re-import the JSON to restore it.
