2. Understanding Workflow Variables

What Are Variables?

Variables are named placeholders that can be used anywhere in your workflow:

  • URLs: https://api.example.com/users/{{userId}}
  • Headers: Authorization: Bearer {{token}}
  • Request bodies: {"name": "{{userName}}"}

Variable Syntax

Use double curly braces to reference a variable:

{{variableName}}

Where Variables Come From

SourceDescriptionExample
Workflow Defaults Defined when creating the workflow userId = "1"
Initial Variables Edited in Workflow Runner before test Override userId = "5"
Extractions Extracted from HTTP responses during execution postId from $.id

3. The Initial Variables Panel

When you select a workflow in the Workflow Runner, you'll see the Initial Variables panel.

Panel Components

ComponentDescription
Variable rows Each workflow variable with its current value
Edit inputs Text fields to change variable values
"Modified" badge Shows when values differ from workflow defaults
Reset button Restores all variables to workflow defaults
History button Opens the Variable History panel
💡 Variables Available to All Steps The text below the panel header reminds you: "Variables available to all steps via {{name}}."

4. Hands-On Exercise: Country Lookup Workflow

Let's create a workflow that uses variables to search for different countries.

Step 1: Create the Workflow

  1. Go to Workflow → Designer
  2. Click + New Workflow
  3. Name it "Country Lookup"

Step 2: Add Variables

  1. Click the Variables panel on the right
  2. Add these variables:
{{countryName}} = "germany"
{{fields}} = "name,capital,population"

Step 3: Add HTTP Nodes

1Search Country

Add an HTTP node with:

Method: GET
URL: https://restcountries.com/v3.1/name/{{countryName}}?fields={{fields}}

Add extraction: countryCode from $[0].cca2

2Get Country Details

Add another HTTP node with:

Method: GET
URL: https://restcountries.com/v3.1/alpha/{{countryCode}}

Step 4: Connect and Save

Connect: Start → Search Country → Get Country Details

Save the workflow.

5. Running with Different Variables

Exercise A: Run with Defaults

  1. Go to Testing → Workflow Runner
  2. Select "Country Lookup"
  3. Observe the Initial Variables panel shows: 
    {{countryName}} = germany
{{fields}} = name,capital,population
  4. Click ▶ Run Workflow
  5. Watch the test complete — it searches for Germany

Exercise B: Change Variables and Run Again

  1. In the Initial Variables panel, change: 
    {{countryName}} = japan
  2. Notice the (modified) badge appears
  3. Click ▶ Run Workflow
  4. This run searches for Japan instead

Exercise C: Use Variable History

  1. Click the 📜 History (2) button
  2. You'll see two saved configurations:
    • Japan run (most recent)
    • Germany run
  3. Click the Germany configuration to restore it
  4. The variables reset to countryName = germany

6. Labeling Configurations

Give meaningful names to frequently-used variable sets.

How to Label

  1. Open the Variable History panel
  2. Find the configuration you want to label
  3. Click the ✏️ (edit) icon
  4. Enter a label like "European Test"
  5. Press Enter or click Save

Labeled vs. Unlabeled

UnlabeledLabeled
countryName=germany European Test
countryName=japan Asian Test
💡 Best Practice Label configurations that represent meaningful test scenarios (e.g., "Staging Credentials", "High Volume User", "Edge Case - Empty").

7. Resetting to Defaults

When you've modified variables and want to start fresh:

  1. Look for the Reset link next to the History button
  2. Click it to restore all variables to their workflow-defined defaults
  3. The "(modified)" badge disappears
⚠️ Reset vs. History
  • Reset — Returns to the workflow's original default values
  • History — Restores a previously-run configuration

8. Variable History Storage

How History Works

  • Each time you run a workflow, the current variables are saved
  • History is stored per-workflow (each workflow has its own history)
  • Up to 10 configurations are kept per workflow
  • Oldest configurations are removed when limit is reached

History Panel Features

FeatureDescription
Click to restore Click any history item to load its variables
Relative time Shows "2 hours ago", "yesterday", etc.
Edit label ✏️ button to rename the configuration
Delete 🗑️ button to remove from history

9. API Reference

This exercise uses the REST Countries API:

EndpointDescription
GET /v3.1/name/{name} Search countries by name
GET /v3.1/alpha/{code} Get country by 2 or 3 letter code
?fields=a,b,c Limit response to specific fields

Base URL: https://restcountries.com/v3.1
