1. Learning Objectives

By the end of this manual, you will be able to:

  • Read and understand the Workflow Execution Summary
  • Interpret pass rate at the workflow level
  • Analyze per-step metrics in the table
  • Use the Iteration Performance chart
  • Drill into per-iteration detail
  • Identify and debug failed iterations

2. Navigating to Workflow Results

After running a workflow test, click View Full Results → to see detailed metrics.

Alternatively:

  1. Go to Testing → Results in the sidebar
  2. Click the Workflow filter tab at the top
  3. Select a workflow run from the list
💡 Filtering Results The Results page has filter tabs: All, Test, and Workflow. Use the "Workflow" tab to see only workflow runs.

4. The Iteration Performance Chart

Below the summary, you'll find a bar chart showing each iteration's performance.

📊 Iteration Performance Chart
Bar chart showing total duration for each iteration

Reading the Chart

  • X-axis: Iteration number (#1, #2, #3, ...)
  • Y-axis: Total iteration duration in milliseconds
  • Green bars: All steps in this iteration passed
  • Red bars: At least one step failed
  • Dotted line: Average iteration duration

Chart Statistics

Above the chart, you'll see summary stats:

StatDescription
MinFastest iteration
AvgAverage iteration time
p9595th percentile iteration time
MaxSlowest iteration

Tooltip Interaction

Hover over any bar to see details:

Iteration #5: 312ms (2/2 passed)

The Per-Step Metrics table breaks down performance by workflow node.

Column Definitions

ColumnDescription
Step HTTP node label from workflow (numbered)
Count Total executions of this step (= iterations)
Pass % Success rate for this specific step
Avg Average response time
p50 Median response time (50th percentile)
p95 95th percentile response time
Min / Max Fastest and slowest response
💡 Finding Bottlenecks If one step has significantly higher Avg/p95 than others, it's likely a performance bottleneck. Focus optimization efforts there.

6. Per-Iteration Detail

Click ▶ Per-Iteration Detail to expand the iteration list.

Iteration List

Each iteration shows:

  • Status icon: ✅ (all passed) or ❌ (has failures)
  • Iteration number: #1, #2, etc.
  • Total time: Duration in milliseconds
  • Pass count: (2/2 passed)

Expanding an Iteration

Click any iteration to see its individual requests:

▼ ✅ Iteration #3    285ms    (2/2 passed)

7. Debugging Failed Iterations

When you see red bars or ❌ icons, here's how to investigate:

Step 1: Find Failed Iterations

  1. Look for red bars in the Iteration Performance chart
  2. Or expand Per-Iteration Detail and look for ❌ icons

Step 2: Expand the Failed Iteration

  1. Click the failed iteration to expand it
  2. Look for the request with ✗ (fail) status

Step 3: View Request Details

  1. Click the failed request row
  2. A detail modal opens showing:
    • Full URL and method
    • Request headers and body
    • Response status and body
    • Error message (if any)
    • Assertion results (if validation was enabled)

Common Failure Causes

SymptomLikely Cause
Status 0, "Network error" API unreachable, CORS issue, timeout
Status 429 Rate limiting — reduce concurrency
Status 500 Server error — check API logs
Status 404 Resource not found — check URL/extractions
Assertion failed Response didn't match expected — check assertions

8. Hands-On Exercise

Run a 10-iteration test and explore the results.

Setup

  1. Go to Workflow Runner
  2. Select a 2-step workflow (e.g., "Sample: Create → Extract → Verify")
  3. Set: 10 iterations, concurrency 2
  4. Click ▶ Run Workflow
  5. Click View Full Results →

Exploration Tasks

  1. Verify the summary shows: 10 iterations, 2 steps, 20 total requests
  2. Check the pass rate (should be 100% green)
  3. Hover over bars in the Iteration Performance chart
  4. Note which iteration was fastest and slowest
  5. Check the Per-Step Metrics table:
    • Which step is faster on average?
    • What's the p95 for each step?
  6. Expand Per-Iteration Detail
  7. Click on iteration #5 to see its requests
  8. Click a request to open the detail modal
