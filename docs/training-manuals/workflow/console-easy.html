Workflow Console

Real-Time Logs, Timeline View & Debugging — Training Manual

Easy ★☆☆ · Workflow · Debugging

RedfireForge v0.6.0

1. Purpose

The Workflow Console shows real-time log output as your workflow executes. It's the primary debugging tool — see exactly what each node does, when it runs, and what data flows between steps.

2. Opening the Console

  1. Open a workflow in the Workflow Designer.
  2. Click the 🖥️ Console button in the bottom toolbar.
  3. The console panel slides up from the bottom of the designer.

3. Console Views

Log View

The default view. Each log entry has an icon indicating its type:

IconMeaningExample
●Node started"HTTP Request → GET /api/users started"
→Request sent"→ GET https://api.example.com/users"
←Response received"← 200 OK (142ms)"
⬡Data transform"Transform: extracted 10 items from $.data"
✗Error"✗ 500 Internal Server Error"

Timeline View

Switch to Timeline view for a higher-level summary of each step:

  • Step name and node type
  • Duration bar (visual width proportional to time)
  • Status icon (✅/❌/⏸)
  • Click any step to jump to its detailed logs

4. Search & Filter

  1. Type in the 🔍 search box to filter log entries by keyword.
  2. Matching entries are highlighted; non-matching entries are dimmed.
  3. Use the ↑/↓ arrows to navigate between matches.
  4. The match count badge shows "3 of 12 matches" etc.

5. Run Behavior

Control how the console handles logs across multiple runs:

ModeBehavior
Auto-clearClear previous logs when a new run starts (default)
AppendKeep previous logs and append new ones with a separator

Toggle between modes using the ⚙️ gear icon in the console toolbar.

6. Display Modes

Resize and reposition the console to fit your workflow:

ModeHowWhen to Use
BottomDefault — docked to bottom of designerGeneral use
FloatingDrag the console title bar to undockNeed to see the workflow canvas underneath
Full ScreenClick the ⛶ expand buttonDebugging complex logs with lots of output

In Bottom and Floating modes, drag the top edge to resize vertically.

7. Walkthrough

  1. Open a workflow sample from the Gallery (e.g., "Parallel Fan-Out").
  2. Click 🖥️ Console to open the console panel.
  3. Click ▶ Run to execute the workflow.
  4. Watch log entries appear in real time — each node's start/response/complete.
  5. Switch to Timeline view to see the step summary with duration bars.
  6. Click a step in the timeline to jump to its detailed log entries.
  7. Type "error" in the search box — if any errors occurred, they're highlighted.
  8. Toggle to Append mode and run again — both runs' logs are visible.
  9. Try Full Screen mode to see all logs without scrolling.
💡 Pro Tip Use the console alongside the Execution History. The console shows real-time output; history shows persisted results you can review later.

8. Trace Levels & Results Explorer Console

This manual covers the Designer Console — the real-time view during Quick Test execution. RedfireForge also has a Results Explorer Console for reviewing logs after a Workflow Runner execution.

Trace Levels

In the Workflow Runner, you can set a Trace Level that controls how much detail is captured:

LevelWhat's Captured
MinimalPass/fail + error messages only
StandardHTTP status/timing, assertions, variable extractions
FullStandard + complete HTTP request/response bodies
DebugFull + raw console.log() output from Script nodes

The Designer Console (Quick Test) always runs at Debug level for maximum visibility.

Results Explorer Console

After running a workflow from the Workflow Runner, open the Results Explorer and press ⌘J (or click the Console button in the toolbar) to see a per-iteration console. This console reconstructs log lines from the stored trace data — the higher the trace level, the more detail is available.

💡 Two Consoles, One Purpose The Designer Console is live during Quick Test execution. The Results Explorer Console is post-hoc — reviewing stored trace data iteration by iteration after a Workflow Runner execution.
