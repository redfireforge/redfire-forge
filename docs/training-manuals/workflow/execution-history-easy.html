Workflow Execution History

Review Past Runs, Debug Steps & Resume Paused Workflows

Easy ★☆☆ · Workflow · Observability

RedfireForge v0.6.0

1. Purpose

Every workflow run is recorded in the Execution History panel. Use it to review what happened, inspect per-step results, debug failures, and resume paused workflows.

2. Opening Execution History

  1. Open a workflow in the Workflow Designer.
  2. Click the 📜 History button in the toolbar.
  3. The Execution History panel opens on the right side.

3. Filter Types

Use the filter tabs at the top to narrow results:

FilterShows
AllEvery execution regardless of trigger
WebhooksOnly runs triggered by incoming webhooks
SchedulesOnly runs triggered by cron/schedule triggers
PausedWorkflows currently paused at a Wait node

4. The Master-Detail Layout

Master List (Left)

Each execution entry shows:

  • Timestamp — when the run started
  • Status badge — ✅ Success, ❌ Failed, ⏸ Paused, ⏳ Running
  • Trigger type — Manual, Webhook, Schedule
  • Duration — total run time

Detail View (Right)

Click any execution to see its details:

  • Step-by-step results — each node shows its status, duration, and output
  • JSON tree viewer — expand any step's output to inspect the full request/response data
  • Error details — for failed steps, the error message and stack trace are shown

5. Paused Workflows

When a workflow hits a Wait node (correlation wait, manual approval, timer), it pauses. Paused workflows appear in the Paused filter tab.

Resuming a Paused Workflow

  1. Switch to the Paused filter tab.
  2. Find the paused execution — it shows which node it's waiting at.
  3. If it's a manual resume wait, click ▶ Resume Manually.
  4. If it's a timed wait, a live countdown shows the remaining time.
  5. If it's a correlation wait, it resumes automatically when the matching event arrives.
💡 Live Countdown Timed waits display a real-time countdown (e.g., "Resumes in 2m 34s"). You can also click Resume Manually to skip the timer.

6. Per-Step Inspection

  1. In the detail view, click any step in the execution timeline.
  2. The step detail expands, showing:
    • Input — the data/payload the step received
    • Output — the data/payload the step produced
    • Duration — how long the step took
    • Status — pass/fail/skip
  3. Use the JSON tree viewer to drill into nested response objects.

7. Walkthrough

  1. Open any workflow sample from the Gallery (e.g., "Sequential Chain").
  2. Click ▶ Run to execute the workflow.
  3. After completion, click 📜 History.
  4. Your run appears at the top with a ✅ badge.
  5. Click it to see per-step results.
  6. Expand any step's output to view the JSON response.
  7. Run the workflow again — now you have 2 entries in history.
  8. Use the All filter to see both runs.
