1. Purpose & Use Case

This sample demonstrates the filter + enrich pattern — fetching data from an API, then using a SetVariable node to extract and reshape specific fields from the response into clean, usable variables.

Real-world analogy: You receive a complex API response with dozens of fields, but you only need three or four. Instead of passing the raw response downstream, you use SetVariable to pick out exactly what you need and give each piece a clear name.

Examples:

  • Looking up a customer record and extracting just the email and tier
  • Fetching product data and pulling out the price and availability
  • Querying a configuration API and extracting feature flag values
  • Enriching a partial record with additional fields from a lookup API

2. Concepts You'll Learn

  • Using query parameters in HTTP URLs (?fields=) to request only needed data
  • Using a SetVariable node to extract and rename fields from an API response
  • Understanding how JSONPath works with array responses (the API returns an array)
  • Using {{variable}} interpolation in SetVariable expressions
  • Using a Condition node to validate extracted data
  • The filter + enrich pattern for clean data pipelines

5 nodes, 4 edges — a linear pipeline. The HTTP node fetches filtered country data, the SetVariable node extracts specific fields, and the Condition node verifies a currency was found.

4. Node-by-Node Walkthrough

S Start Node

Input VariablescountryName = "japan"

The workflow starts with a country name. You can change this to any country (e.g., brazil, germany, australia).

1 Search Country (HTTP Node)

URLhttps://restcountries.com/v3.1/name/{{countryName}}?fields=name,currencies,capital,region
MethodGET
HeadersAccept: application/json
ExtractionscountryJson ← $[0] (first result)

Calls the REST Countries API with field filtering. The ?fields= parameter tells the API to return only the fields we need, reducing response size. The API returns an array — we extract the first match with $[0].

📘 Why Use Field Filtering? The full country response contains 30+ fields (translations, borders, timezones, etc.). By specifying ?fields=name,currencies,capital,region, we get a focused response that's easier to work with and faster to transfer.

2 Extract Currency (SetVariable Node)

Variables capital ← extracted from countryJson → capital[0]
region ← extracted from countryJson → region
currencyCode ← first key of currencies object (e.g., "JPY")

The SetVariable node picks out individual fields from the country JSON and stores them as named variables. The currency object uses currency codes as keys (e.g., {"JPY": {"name": "Japanese yen", "symbol": "¥"}}), so we extract the first key as the currency code.

3 Has Currency? (Condition Node)

Left{{currencyCode}}
Operator!= (not equal)
Right (empty string)

Verifies a currency code was extracted. Some territories may not have a currency. The true branch connects to Done.

E Done (End Node)

Marks the workflow as complete. Variables capital, region, currencyCode, and lookupComplete are available.

6. Step-by-Step Development Guide

Follow these steps to build this workflow from scratch:

  1. Load from Template Gallery.
    Click New Workflow → Template Gallery. Find "🌍 Country Currency Lookup" in the API Patterns category. Click Use Template.

    — OR build manually: —
  2. Create a new workflow.
    Click Workflows → + New. Name it "Country Currency Lookup". Add input variable countryName with default value japan.
  3. Add the HTTP node (Search Country).
    Drag an HTTP node onto the canvas. Configure:
    • URL: https://restcountries.com/v3.1/name/{{countryName}}?fields=name,currencies,capital,region
    • Method: GET
    • Extractions: Add countryJson ← $[0]
    Connect Start → HTTP.
  4. Add the SetVariable node (Extract Currency).
    Drag a SetVariable node. Configure:
    • capital ← extract from countryJson → capital[0]
    • region ← extract from countryJson → region
    • currencyCode ← extract first key of currencies object
    • lookupComplete ← true
    Connect HTTP → SetVariable.
  5. Add the Condition node.
    Drag a Condition node. Configure:
    • Left: {{currencyCode}}
    • Operator: !=
    • Right: (leave empty)
    Connect SetVariable → Condition. Connect Condition (true) → End.
  6. Run the workflow.
    Click Quick Test. Verify the currency code for Japan is JPY and the Condition passes.

8. Try It Yourself — Exercises

Exercise 1: Try Different Countries

Change countryName to brazil, germany, or india. Observe how the currency code changes (BRL, EUR, INR).

Exercise 2: Extract Currency Name and Symbol

The currencies object contains not just the code but also name and symbol. Add variables for currencyName (e.g., "Japanese yen") and currencySymbol (e.g., "¥").

Exercise 3: Add Population Data

Add population to the ?fields= parameter. Extract it as a variable. Add a second Condition node that checks if the population is greater than 1,000,000.

Exercise 4: Handle "Country Not Found"

Try countryName = "atlantis". The API returns a 404. Add an error handler or a Condition node that checks the HTTP status code before proceeding to the SetVariable node.
