Workflows Gallery

Overview — Training Manual

The Workflows Gallery provides 30 ready-to-run workflow samples across 5 categories and 8 subdirectories, covering API orchestration, flow control, event-driven patterns, async correlation, scripting, and more.

RedfireForge v0.8.0

1. What is the Workflows Gallery?

The Workflows Gallery is a curated collection of 30 workflow samples built into RedfireForge. Each sample demonstrates a real-world automation pattern — from simple sequential API calls to advanced multi-region deployment orchestrations with sub-workflows, async correlation, and error handling.

Samples are organized into 5 categories (API Patterns, Flow Control, Event-Driven, Orchestration, and cross-cutting themes) spread across 8 subdirectories. Difficulty levels range from Easy through Medium to Advanced, so you can progress from basic chaining to complex parallel pipelines at your own pace.

💡 Tip Each subdirectory has its own dedicated training manual with detailed walkthroughs. This overview helps you navigate the full collection and choose where to start.

2. How to Use Workflow Samples

  1. Open the Gallery panel from the RedfireForge sidebar.
  2. Navigate to the Workflows tab.
  3. Browse or filter by category/difficulty, then click a sample to expand its details.
  4. Choose an action:
    • Import — adds the workflow to your workspace so you can study and customize it.
    • Open in Editor — launches the workflow in the visual Workflow Editor where you can inspect each node, its configuration, and connections.
    • Run — executes the workflow immediately and shows results in the console.
  5. Study the node graph: hover over nodes to see their config, trace variable flow between steps, and examine condition expressions.
📋 Note Samples that require a local server (e.g., async correlation workflows) will indicate localhost:3001 in their live API list. Start the RedfireForge server before running those samples.

5. Learning Path

Follow this suggested progression to build workflow skills from foundational concepts to advanced orchestration.

Stage 1 — Foundations

Start with simple sequential and parallel patterns to learn node basics and variable chaining.

  1. Create → Extract → Verify Easy — sequential HTTP calls, variable extraction
  2. Parallel API Calls Easy — Fork/Join pattern for concurrent requests
  3. Conditional Branching Easy — If/Else routing based on response data
  4. Script: JSON Formatter Easy — your first Script node

Stage 2 — Event Triggers & Real APIs

Learn how workflows start and explore diverse public APIs.

  1. Webhook Trigger Easy — incoming HTTP webhook
  2. Schedule Trigger Easy — cron-based scheduling
  3. Pokémon Evolution Chain Easy — linked resource traversal
  4. Country Currency Lookup Easy — search & filter patterns

Stage 3 — Intermediate Patterns

Add loops, switches, multi-API composition, and validation.

  1. Switch Order Router Medium — multi-way branching
  2. Paginated API Fetcher Medium — while-loop with aggregation
  3. Product Search & Cart Medium — e-commerce API composition
  4. Script: Cross-API Validator Medium — script-based data validation
  5. Manager Approval Workflow Medium — async correlation with timeout

Stage 4 — Advanced Orchestration

Master error handling, sub-workflows, and complex async patterns.

  1. Resilient API with Error Handling Advanced — retry & error capture
  2. Workflow Error Handler Advanced — workflow-level failure notification
  3. Sub-Workflow Orchestrator Advanced — parent/child orchestration
  4. Multi-Region Deploy Orchestrator Advanced — Fork/Join + sub-workflows + rollback
  5. Parallel Payment Processing Advanced — dual correlation waits with aggregation
  6. Script: Data Pipeline & Report Advanced — full ETL pipeline with script nodes
💡 Tip Don't forget the Node Reference guide in node-reference/ — it covers every node type (HTTP, Condition, Loop, Fork/Join, Script, CorrelationWait, and more) with configuration details and best practices.
