API Mock: Folder Organisation

Medium   Folder Tree · Context Menus · Drag Reorder · Undo Toast

What You Will Learn

  • Create folders to group related routes
  • Move routes into folders by drag or context menu
  • Rename and delete folders
  • Reorder routes within a folder by dragging
  • Use the undo toast to recover from accidental edits

The Route Sidebar Structure

The left sidebar shows a tree of folders at the top and uncategorised routes below. Folders collapse/expand with the ▶ chevron. Folders are purely organisational — they do not affect route priority or matching.

Part A — Create a Folder

1
Right-click any blank area in the sidebar (not on a route). Choose New Folder from the context menu. Alternatively, click the + folder icon at the top of the sidebar.
2
Type a name for the folder — e.g. Auth Routes — and press Enter. The folder appears at the top of the list.
3
Create two more folders: User Endpoints and Error Scenarios.

Part B — Move Routes into Folders

4
Drag method: click and hold a route row, then drag it onto a folder name. Release when the folder is highlighted. The route moves into the folder.
5
Context menu method: right-click a route → Move to folder → select a folder from the sub-menu. If no folders exist yet, you are prompted to create one.
6
Move your GET /login and POST /logout routes into Auth Routes. Move all user-related routes into User Endpoints.

Part C — Rename a Folder

7
Double-click the folder name to enter edit mode. Type the new name and press Enter or click elsewhere to confirm. Press Esc to cancel.
8
Alternatively, right-click the folder → Rename.

Part D — Reorder Routes

9
Within a folder, drag route rows up or down to reorder them. The order affects how conflicts are displayed in the Conflicts inspector (routes higher in the list have higher priority by default).
10
You can also drag routes between folders in the same drag operation — drop onto the target folder or between two routes inside an expanded folder.

Part E — Delete a Folder

11
Right-click a folder → Delete folder. A confirmation dialog appears with two options:
  • Delete routes too — removes the folder and all routes inside it
  • Move routes to root — removes the folder but keeps routes (moves them to uncategorised)

The Undo Toast

12
After any destructive action (delete route, delete folder, move route), a toast notification appears in the bottom-right corner with an Undo button. You have 5 seconds to click it.
13
To test: delete a route, then immediately click Undo in the toast. The route and its entire configuration are restored.
⚠️ Undo window The undo toast expires after 5 seconds. After that, the action cannot be undone. For large deletions, verify your selection before confirming.

💡 Organisation tip Use folders to mirror your API's resource groups (e.g. Users, Orders, Webhooks) or by scenario type (Happy Paths, Error Cases, Auth Flows). Collapsed folders keep large route libraries manageable.

Self-Practice Exercises

  1. Create 10 dummy routes and organise them into 3 folders. Verify the sidebar shows a clean tree.
  2. Drag a route from one folder to another. Verify it appears in the destination folder.
  3. Delete a folder using "Move routes to root". Verify the routes are now uncategorised.
  4. Delete a route and click Undo within 5 seconds. Verify the route is restored with all its configuration intact.
