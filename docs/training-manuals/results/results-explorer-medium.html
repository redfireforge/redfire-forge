Results Explorer: Canvas & Node Detail

Medium   Open Explorer · Workflow Canvas · Node Detail Tabs · Iterations · Console

What You Will Learn

  • Open the Results Explorer modal for a workflow run
  • Read the execution canvas: pass/fail/skipped colours, node badges
  • Search and filter nodes by state
  • Click a node to open its detail panel and navigate all five tabs
  • Switch between aggregate view (all iterations) and a single iteration
  • Open the Console panel and filter log output by node
  • Expand the Iteration Matrix Table

Prerequisites

You need at least one workflow run with an execution trace. Workflow runs with a trace show the 📊 Results Explorer button in the header action bar. Test-only runs (no workflow) do not have the Explorer.

Step-by-Step Walkthrough

Part A — Open the Results Explorer

1
Select a workflow run using the run selector (look for the ⚡ icon in the run label). The 📊 Results Explorer button becomes active in the header.
2
Click 📊 Results Explorer (test ID results-explorer-open-btn). A full-screen modal opens. If the trace is large, a spinner shows while it decompresses: ⏳ Loading trace…
3
The modal has three regions:
  • Left panel — the workflow execution canvas (diagram with coloured nodes)
  • Right panel — node detail (hidden until you select a node)
  • Bottom strip — collapsed by default: Iteration Matrix Table

Part B — Read the Execution Canvas

4
Every node in the canvas is coloured by its final execution state:
  • 🟢 Green border — pass
  • 🔴 Red border — fail
  • Grey border — skipped
  • Purple border — sub-workflow node (pass)
5
In the canvas toolbar, use the state filter dropdown (All / Pass / Fail / Skipped) to dim nodes not matching the filter. Select Fail — only failing nodes remain fully opaque.
6
Use the search input in the canvas toolbar. Type part of a node name (e.g. Auth). Matching nodes highlight; others dim.
7
Click the Fit View button to reset the canvas zoom and center all nodes. Toggle the Minimap button to show/hide the overview minimap in the corner.

Part C — Select a Node and Read Detail Tabs

8
Click any node on the canvas. The right panel opens showing the node's name, type, and five tabs.
9
Overview tab (default) — shows aggregate statistics for this node across all iterations:
  • Total invocations, pass count, fail count
  • Duration stats: avg, P95, min, max
  • For nodes with retries or wait steps: wait duration stats
10
Request tab — the outgoing HTTP (or gRPC/WS/etc.) request for the selected iteration: method, URL, request headers, request body.
11
Response tab — HTTP status code, response headers, response body (JSON tree view with expand/collapse). For large bodies, scroll within the panel.
12
Variables tab — the variable scope snapshot at the time this node executed: each variable name and its value at that point in the workflow.
13
Assertions tab — lists every assertion configured on this node with pass/fail indicator, expected value, and actual value. Failed assertions show the mismatch prominently.

Part D — Switch Iterations

14
If the workflow ran more than one iteration, an Iteration Picker appears above the detail panel: Iteration 1 of N ▾. Click it to select a specific iteration index.
15
Selecting iteration 3 updates the detail panel to show that iteration's specific request/response/variables/assertions. The canvas may also highlight the selected iteration's state on each node.
16
To return to aggregate view (all iterations combined), select All iterations from the iteration picker.

Part E — Iteration Matrix Table

17
Click the ▲ Iterations collapse control at the bottom of the modal to expand the Iteration Matrix Table.
18
The table shows rows = nodes, columns = iterations. Each cell shows the node's state for that iteration (green/red/grey) and duration. Hover a cell for a tooltip.
19
Click any cell to jump directly to that node × iteration — the canvas selects the node and the iteration picker switches to that iteration.

Part F — Open the Console Panel

20
In the Explorer modal toolbar, click the Console button. The console panel docks to the bottom of the modal.
21
The console shows log lines from the run: requests, responses, assertions, variable assignments, and errors. Each line shows the node name, log level, and message.
22
Use the Node filter dropdown to show log lines from a single node only. This isolates the output of a specific step when troubleshooting.

💡 Fastest failure diagnosis in the Explorer 1) Set state filter to Fail — only failing nodes show fully. 2) Click the red node. 3) Go to Assertions tab to see exactly which check failed and why. 4) Switch to Response tab to see the actual server response.

Self-Practice Exercises

  1. Open the Explorer on a multi-iteration run. Select iteration 2 in the picker. Compare the Response body on iteration 2 vs iteration 1 for the same node.
  2. Use the canvas search to find a specific node by name. Then filter by Fail state. Note how these two filters compose.
  3. Expand the Iteration Matrix Table. Click a cell where the node shows a fail state. Verify the detail panel switches to that iteration and the Assertions tab shows the failure.
  4. Open the Console. Filter to a single failing node. Read the log lines to understand the failure sequence.
