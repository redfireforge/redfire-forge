Results Dashboard

The Results Dashboard is where all test and workflow run data lives — metrics, SLA evaluation, run comparison, and deep execution inspection.

Dashboard Layout

The dashboard has three structural layers from top to bottom:

Layer 1 — Run Selection Bar

At the very top: the run type filter tabs (All Runs / 🧪 Test Runs / ⚡ Workflow Runs) and the run selector dropdown. Each entry shows timestamp, project, service, environment, TPS, and status indicators (★ baseline, SLA dot 🟢/🔴/🟡, regression dot R:🟢/🟡/🔴).

Results Explorer Modal

The Results Explorer (📊 button) is a full-screen modal available for workflow runs that have a captured execution trace. It provides:

Left Panel — Execution Canvas

Workflow diagram with pass/fail/skipped colour overlay on every node. Search by node name. Filter by state (all/pass/fail/skipped). Minimap toggle. Fit-view button.

Right Panel — Node Detail

Five tabs: Overview (aggregate stats), Request (method/URL/headers/body), Response (status/headers/body), Variables (scope snapshot), Assertions (pass/fail per check).

Bottom — Iteration Matrix

Collapsible table showing all iterations. Rows = nodes, columns = iterations. Click a cell to jump to that node × iteration. Heat-map colouring by duration.

Timeline View

Toggle the left panel from Diagram to Timeline. Horizontal Gantt bars per node per iteration. Hover for tooltip. Zoom in/out.

Console Panel

Log output for the run. Dockable (bottom strip) or floating window. Filter by node, search text, navigate matches.

Sub-Workflow Drilldown

Click into a Sub-Workflow node to open its inner trace. Breadcrumb bar shows the stack. Back button pops up one level.
