Overview — Training Manual

The Tests Gallery provides 8 ready-to-run test samples covering smoke tests, regression suites, contract validation, security checks, and load profiles — each with multiple scenarios and built-in assertions.

RedfireForge v0.5.4

1. What are Test Samples?

Test samples are pre-built multi-scenario test suites available in the RedfireForge Tests Gallery. Unlike individual request samples, each test contains multiple scenarios that run sequentially against one or more APIs. Every scenario includes built-in assertions that automatically validate the response — checking status codes, response body structure, data types, array lengths, and more.

Test samples are organized by difficulty (Easy, Medium, Advanced) and by category (smoke, regression, contract, security, load) so you can focus on the testing discipline most relevant to your needs.

💡 Tip Test samples are the best way to learn how RedfireForge's assertion engine works. Import a sample, run it, and inspect the pass/fail results to understand each assertion type.

2. How to Use Test Samples

  1. Open the Gallery panel from the RedfireForge sidebar.
  2. Navigate to the Tests tab.
  3. Browse the list and click on any test to expand its details, including the scenario list and assertion summary.
  4. Choose an action:
    • Import Test — adds the test and all its scenarios to your workspace.
    • Run Test — imports and immediately executes all scenarios, displaying pass/fail results.
  5. After execution, review the Results Panel to see which scenarios passed, which failed, and the details of each assertion.
📋 Note Imported tests are fully editable — you can add, remove, or modify scenarios and assertions to match your own testing needs.

4. Test Categories

Each test sample belongs to a category that describes the testing discipline it demonstrates:

Smoke

Quick, lightweight tests that verify an API is up and responding correctly. Smoke tests check basic connectivity, expected status codes, and minimal response structure. They are the first line of defense and should pass before any deeper testing begins. Examples: User API Smoke Test, Product Listing Check.

Regression

Comprehensive tests that verify existing functionality has not broken after changes. Regression suites cover multiple endpoints, edge cases, and data consistency checks. They are typically run after deployments or code changes. Examples: Paginated API Regression, Country Search Suite, E-Commerce Full Suite.

Contract

Tests that validate the API response conforms to an expected schema or contract — verifying that required fields exist, data types are correct, and the structure matches documentation. Contract tests catch breaking API changes early. Example: Pokémon Data Contract.

Security

Tests that verify authentication flows, authorization boundaries, and error handling for unauthorized access. Security tests ensure that protected endpoints reject invalid credentials and return appropriate error responses. Example: Auth Flow Validation.

Load

Tests that simulate concurrent requests across multiple endpoints to evaluate performance under load. Load profiles help identify bottlenecks, timeout thresholds, and degradation patterns. Example: Multi-API Load Profile.

5. Learning Path

Follow this suggested progression to build your API testing skills incrementally:

Step 1 — Smoke Tests

Start with the Easy smoke tests: User API Smoke Test and Product Listing Check. These have simple assertions (status code, array presence) and help you understand how scenarios and assertions work in RedfireForge.

Step 2 — Regression & Contract

Move on to the Medium tests: Paginated API Regression, Pokémon Data Contract, and Country Search Suite. These introduce more assertion types (numeric comparisons, regex matching, array length validation) and test edge cases like out-of-range pagination and 404 handling.

Step 3 — Security & Authentication

Try Auth Flow Validation to understand how to test login flows, token validation, and unauthorized access scenarios.

Step 4 — Advanced Suites & Load

Finish with the Advanced tests: E-Commerce Full Suite (a comprehensive multi-endpoint regression) and Multi-API Load Profile (concurrent requests across 5 APIs). These demonstrate how to build production-grade test suites.

💡 Tip After running a test sample, try adding your own scenarios or modifying assertions to deepen your understanding of RedfireForge's testing capabilities.
