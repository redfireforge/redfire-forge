Get All Users

Easy Sample — Training Guide

Fetch a complete list of users from a mock REST API. This sample demonstrates the simplest form of a GET request — no parameters, no headers, just a clean URL returning structured JSON data.

RedfireForge v0.5.4
Difficulty: ★☆☆
GET · jsonplaceholder.typicode.com

1. Purpose & Use Case

This request fetches an array of 10 user objects from the JSONPlaceholder API — a free, publicly available REST API designed for testing and prototyping. It's one of the most commonly used mock APIs in the developer community.

Real-world analogy: Imagine opening your company's employee directory and seeing every person listed with their name, email, phone number, and department. This API call does exactly that — it returns a "phone book" of users in a single request.

This is an ideal first sample because:

  • No authentication is required.
  • No request body or headers are needed.
  • The response is a clean JSON array with consistent structure.
  • The API always returns the same 10 users, making results predictable.

2. Concepts You'll Learn

  • HTTP GET method — the standard method for retrieving data without modifying anything on the server.
  • JSON array response — how APIs return lists of objects wrapped in a JSON array ([ {...}, {...} ]).
  • Nested JSON objects — each user contains nested objects like address (with its own geo sub-object) and company.
  • HTTP status code 200 — the standard "OK" response indicating the request was successful.
  • Content-Type header — the response comes back as application/json; charset=utf-8.
  • Response inspection — how to read and navigate a structured API response in RedfireForge.

PropertyValue

📋 Note JSONPlaceholder is a free API with no rate limiting for reasonable usage. It always returns the same static dataset, making it perfect for learning and testing.

5. Step-by-Step Guide

Step 1 — Open the Gallery

Launch RedfireForge and click the Gallery icon in the sidebar. Navigate to the Requests tab.

Step 2 — Find the Sample

Scroll to find Get All Users (marked with 👥) or use the search bar. It's tagged as Easy.

Step 3 — Import the Sample

Click on the sample card to expand its details. Press Send Request to import it into your workspace and execute it immediately, or press Try It to preview the request configuration first.

Step 4 — Run the Request

If you chose "Try It", review the request details in the editor panel, then click Send to execute. The response will appear in the response panel below.

Step 5 — Inspect the Response

In the response panel, observe:

  • Status: 200 OK — the request was successful.
  • Body: A JSON array containing 10 user objects.
  • Headers: Note the Content-Type: application/json header.
  • Time: The response time in milliseconds (typically 100–300ms).
📋 Note Click on any user object in the response viewer to expand and collapse nested fields like address and company.

6. Try It Yourself

Now that you've run the sample, try these exercises to deepen your understanding:

Exercise 1 — Fetch a Single User

Modify the URL to fetch only the user with ID 1 by appending /1 to the URL:

GET https://jsonplaceholder.typicode.com/users/1

How does the response differ? (Hint: it's a single object, not an array.)

Exercise 2 — Filter by Username

Add a query parameter to filter users by username:

GET https://jsonplaceholder.typicode.com/users?username=Bret

How many results do you get? What's the response structure?

Exercise 3 — Fetch User's Posts

JSONPlaceholder supports nested resources. Try fetching all posts by user 1:

GET https://jsonplaceholder.typicode.com/users/1/posts

How many posts does user 1 have? What fields does each post contain?

💡 Tip Each exercise builds on the previous one. Start with Exercise 1 and work your way through — they get progressively more interesting!
