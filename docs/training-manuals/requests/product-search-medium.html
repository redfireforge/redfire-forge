Product Search with Query

Medium Sample — Training Guide

Search a product catalog by keyword and explore rich product data including prices, brands, categories, and images. This sample demonstrates how e-commerce search APIs work behind the scenes.

RedfireForge v0.6.0
Difficulty: ★★☆
GET · dummyjson.com

1. Purpose & Use Case

This request searches the DummyJSON product catalog for items matching the keyword "phone." The API returns a filtered list of products with detailed information including pricing, brand, category, and thumbnail images — closely mimicking real e-commerce search endpoints.

Real-world analogy: Imagine typing "phone" into an online store's search bar. Behind the scenes, the store's API receives your search query, filters its product database, and returns matching items with their names, prices, images, and other details. This sample replicates that exact workflow.

This sample is Medium difficulty because:

  • It uses a dedicated search endpoint (/products/search) with a query parameter.
  • The response contains rich, multi-field product objects with various data types.
  • Results include pagination metadata (total, skip, limit).
  • It demonstrates a common e-commerce API pattern used by virtually every online store.

2. Concepts You'll Learn

  • Search queries — using the q parameter to search for products by keyword, similar to how search bars work on websites.
  • Product data — understanding a typical product schema with fields like title, price, brand, category, and thumbnail.
  • Filtering results — how the API filters its catalog to return only products matching your search term.
  • Mixed data types — the response contains strings, numbers, decimals, and URLs all in one object.
  • Search vs. list endpoints — comparing /products/search?q=phone with /products (which returns all products).
  • Pagination in search results — search APIs still include total, skip, and limit for navigating through many results.

3. Request Details

PropertyValue
MethodGET
URLhttps://dummyjson.com/products/search?q=phone
HeadersNone required
BodyNone (GET requests do not have a body)
Query Parametersq=phone
📋 Note The search endpoint /products/search is separate from the main /products endpoint. The q parameter searches across product titles and descriptions, returning only matching items.

5. Step-by-Step Guide

Step 1 — Open the Gallery

Launch RedfireForge and click the Gallery icon in the sidebar. Navigate to the Requests tab.

Step 2 — Find the Sample

Scroll to find Product Search with Query (marked with 🔍) or use the search bar. It's tagged as Medium.

Step 3 — Import the Sample

Click on the sample card to expand its details. Press Send Request to import it into your workspace and execute it immediately, or press Try It to preview the request configuration first.

Step 4 — Run the Request

If you chose "Try It", review the URL and note the q=phone query parameter in the editor panel. Click Send to execute.

Step 5 — Inspect the Response

In the response panel, observe:

  • Status: 200 OK — the search was successful.
  • Body: A JSON object with a products array and pagination metadata (total, skip, limit).
  • Product fields: Each product has id, title, description, price, brand, category, and thumbnail.
  • Time: The response time in milliseconds (typically 100–300ms).
📋 Note The total field shows how many products matched your search query — not the total number of products in the catalog. Try different search terms to see how total changes.

6. Try It Yourself

Now that you've run the sample, try these exercises to deepen your understanding:

Exercise 1 — Search for a Different Product

Change the search query to find a different type of product:

GET https://dummyjson.com/products/search?q=laptop

How many results does total show? Are the products all in the same category?

Exercise 2 — Compare Search vs. List

Fetch all products without a search filter:

GET https://dummyjson.com/products?limit=5

How does the response structure compare? What's the total number of products in the entire catalog?

Exercise 3 — Search with No Results

Try searching for something that doesn't exist in the catalog:

GET https://dummyjson.com/products/search?q=spaceship

What does the response look like when there are no matches? Is the products array empty? What is total?

💡 Tip Understanding how search APIs behave with zero results is important for testing. A well-designed API returns a 200 OK with an empty array — not an error. Always test your edge cases!
