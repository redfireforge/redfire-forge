Event Log, Filtering & Bookmarks

Medium   Event rows · Event detail panel · Text search · Type filter · Bookmarks · Clear · Export JSON

What You Will Learn

  • Read event rows: timestamp, type badge, data preview, byte size
  • Click a row to open the event detail panel (full data, JSON auto-detect, Last-Event-ID)
  • Search events by text across data and event type
  • Filter events by event type using the dynamic dropdown
  • Bookmark individual events and filter to bookmarked-only view
  • Clear the event buffer and export all events as JSON
Prerequisite Complete Your First SSE Connection first, or be connected to a live SSE endpoint that sends multiple event types. Use https://sse.dev/test if you need a quick stream.

The Event Log Toolbar

ControlWhat it Does
Search boxLive text filter — matches event data and event type in a single input
Type filter dropdownSelect a specific event type; populated dynamically from types seen in the stream; blank = show all
Bookmark filter toggleWhen active, hides all non-bookmarked events
Clear buttonEmpties the in-memory event buffer; the connection stays open
Export buttonDownloads sse-events-<timestamp>.json containing all buffered events

Step-by-Step Walkthrough

Part 1 — Understanding Event Rows

1
Connect to https://sse.dev/test and wait 5 seconds for events to accumulate. Make sure the right pane shows the Events tab.
2
Look at the event rows. Each row contains:
  • ★ / ☆ — bookmark toggle (leftmost)
  • Timestamp — local time the event was received
  • Event-type badge — colour-coded label (e.g. message, price-update, heartbeat)
  • Data preview — first 120 characters of the event data
  • Size — byte size of the data field
3
The list is virtualised — scrolling is smooth even with thousands of events. Only visible rows are rendered in the DOM.

Part 2 — Event Detail Panel

4
Click any event row. A detail panel slides in below the row (or replaces the right portion of the pane depending on layout). The panel shows:
  • Type — event type badge
  • Last-Event-ID — only shown if the server sent an id: field for this event
  • Size — byte count
  • Timestamp — full local time
  • Data — full data payload; if the data is valid JSON it is automatically pretty-printed and a JSON badge appears in the header
5
Find an event whose data looks like JSON (curly braces in the preview). Click it. Confirm the Data section shows indented, readable JSON. The JSON badge confirms auto-detection.
6
Click the same row again — the detail panel closes (toggle behaviour).

Part 3 — Text Search

7
In the event log toolbar, click the search box and type a word that appears in one of the event data payloads (e.g. greeting or price).
8
The list instantly filters to show only rows whose data or event type contains the text. The count in the status strip reflects the unfiltered total — the search is client-side only.
9
Try typing an event type name (e.g. heartbeat). The filter matches event type fields as well — useful when event types are descriptive but payloads are small.
10
Clear the search box to restore all events.

Part 4 — Event Type Filter

11
Click the Type filter dropdown. It lists every distinct event type received so far (e.g. message, heartbeat). The list updates as new types arrive.
12
Select one event type. Only events of that type are shown. This is faster than text search when event types are the main dimension of interest.
13
You can combine the type filter with the text search — both apply simultaneously. Clear the type filter by selecting the blank option at the top of the dropdown.

Part 5 — Bookmarks

14
Find an interesting event. Click the ☆ (star) icon at the left of the row. It turns to ★ and the row highlights — this event is now bookmarked.
15
Bookmark 2–3 more events across different event types.
16
Click the Bookmark filter toggle button in the toolbar. The list collapses to show only your bookmarked events, regardless of search or type filter.
17
Toggle the bookmark filter off to return to the full list. Bookmarks persist in the session until you clear events or close the tab.

Part 6 — Clear and Export

18
Click Export. Your browser downloads a file named sse-events-YYYY-MM-DDTHH-MM-SS.json. Open the file — it is a JSON array of event objects including id, timestamp, eventType, data, size, and lastEventId fields.
19
Click Clear. All events are removed from the in-memory buffer. The connection stays open — new events immediately start appearing again.
20
Note: clearing also resets all bookmarks and the selected-event detail panel.

Filter Interaction Rules

Active FiltersResult
Text search onlyAll events matching text in data or type
Type filter onlyAll events of selected type
Bookmark filter onlyAll bookmarked events regardless of type or data
Text + typeEvents matching BOTH filters simultaneously
Text + type + bookmarkBookmarked events matching both text and type
NoneAll events in arrival order (newest at bottom)
Buffer limit The event buffer holds up to 10,000 events. When the limit is reached, the oldest events are automatically dropped. Export before clearing if you need to preserve the full history.

Practice Exercises

  1. Connect to a stream that sends mixed event types. Find the rarest type using the type filter and export only those events.
  2. Bookmark all JSON events. Switch to bookmark-only view and verify the count.
  3. Run a search for a specific field name (e.g. "id"). How many events contain it?
