Correlation Wait API

OpenAPI Catalog Spec — Training Manual

Medium ★★☆ · Webhooks · localhost:3001

RedfireForge v0.8.0

1. Purpose & Use Case

The Correlation Wait API spec defines the webhook endpoints used by RedfireForge's async correlation features. It documents 9 endpoints for pausing workflows, receiving callbacks, and managing async operations.

Import this spec to:

  • Explore available webhook endpoints interactively
  • Generate test requests for correlation testing
  • Understand the callback payload schemas

3. Available Endpoints

MethodPathDescription
POST/webhooks/registerRegister a new correlation wait
POST/webhooks/callback/:typeReceive a callback by type (payment, approval, etc.)
GET/webhooks/status/:correlationIdCheck wait status
DELETE/webhooks/cancel/:correlationIdCancel a pending wait
GET/webhooks/pendingList all pending waits
POST/webhooks/timeout/:correlationIdForce timeout a wait
GET/webhooks/historyView callback history
POST/webhooks/replay/:correlationIdReplay a historical callback
GET/healthServer health check

4. Step-by-Step Tutorial

Step 1: Import the Spec

  1. Open the Gallery panel.
  2. Filter by API Catalog domain.
  3. Find "Correlation Wait API".
  4. Click Import to Catalog.

Step 2: Explore Endpoints

  1. Go to the API Catalog tab.
  2. Expand the imported spec.
  3. Click any endpoint to see its schema, parameters, and example payloads.

Step 3: Test an Endpoint

  1. Click the /health endpoint.
  2. Click Try It (requires local server running).
  3. View the response.
💡 Generate Test Requests Right-click any endpoint and select "Export to Requests" to create a request definition you can customize and save.
