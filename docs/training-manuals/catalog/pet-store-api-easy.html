1. Purpose & Use Case

The Pet Store API is the classic example used in OpenAPI/Swagger documentation. It provides a fully-functional REST API for managing pets, orders, and users.

Use this spec to:

  • Learn API Catalog features with a familiar example
  • Practice CRUD operations (Create, Read, Update, Delete)
  • Test against a live public API

3. API Categories

🐾 Pet Operations

MethodPathDescription
GET/pet/{petId}Find pet by ID
POST/petAdd a new pet
PUT/petUpdate existing pet
DELETE/pet/{petId}Delete a pet
GET/pet/findByStatusFind pets by status
GET/pet/findByTagsFind pets by tags

🛒 Store Operations

MethodPathDescription
GET/store/inventoryReturns pet inventories
POST/store/orderPlace an order
GET/store/order/{orderId}Find order by ID
DELETE/store/order/{orderId}Delete order

👤 User Operations

MethodPathDescription
POST/userCreate user
GET/user/{username}Get user by name
PUT/user/{username}Update user
DELETE/user/{username}Delete user
GET/user/loginLogs user in

4. Step-by-Step Tutorial

Step 1: Import the Spec

  1. Open the Gallery and find "Pet Store API".
  2. Click Import to Catalog.
  3. The spec appears in your API Catalog.

Step 2: Try a GET Request

  1. Expand the Pet category.
  2. Click GET /pet/{petId}.
  3. Enter pet ID: 1
  4. Click Try It.

Step 3: Create a Test Request

  1. Right-click the endpoint.
  2. Select Export to Requests.
  3. Customize and add assertions.
  4. Save to your Requests collection.
💡 Quick Test Tip Use the "Find pets by status" endpoint with ?status=available to get a list of pets, then use one of their IDs for other operations.

6. Testing Ideas

  • CRUD flow — Create pet → Read → Update → Delete
  • Status filtering — Test /pet/findByStatus?status=sold
  • Invalid IDs — Test /pet/99999 for 404
  • Order lifecycle — Place order → Check status → Delete
