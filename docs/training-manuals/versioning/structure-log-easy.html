Structure Change Log

Track Scenario, Test & Group Changes Over Time

Easy ★☆☆ · Versioning · Audit Trail

RedfireForge v0.5.6

1. Purpose

The Structure Change Log records every structural modification to your test suite — adding, renaming, deleting, or reordering scenarios, tests, and functional groups. It's your audit trail for "who changed what, and when."

2. Opening the Structure Log

  1. In the main test suite view, locate a Functional Group.
  2. Click the 📋 History button (with the count badge showing the number of changes).
  3. The Structure Change Log panel opens.
Scope The structure log is per-functional-group. Each FG has its own change history.

3. Action Types

The log records 11 types of structural actions:

CategoryActions
ScenarioAdd Scenario, Rename Scenario, Delete Scenario, Reorder Scenario
TestAdd Test, Rename Test, Delete Test, Move Test (between scenarios)
Functional GroupAdd FG, Rename FG, Delete FG

4. Log Entry Format

Each entry shows:

  • Action icon — colored icon indicating the action type (➕ add, ✏️ rename, 🗑️ delete, ↕️ reorder)
  • Description — human-readable summary (e.g., "Added test 'Login Endpoint' to 'Auth Scenario'")
  • Relative timestamp — e.g., "2 minutes ago", "1 hour ago", "Yesterday"
  • Full timestamp — hover to see the exact date and time

5. Filtering

Use the filter buttons at the top to narrow the log:

FilterShows
AllEvery structural change
ScenarioOnly scenario-level changes
TestOnly test-level changes
GroupOnly functional group changes

6. Managing the Log

Clear Log

Click 🗑️ Clear to remove all entries from the structure log. This is useful after a major reorganization when the old history is no longer relevant.

Delete Individual Entries

Hover over any entry and click the ✕ to delete just that entry.

💡 History Badge The History button on each functional group shows a count badge with the number of recorded changes. This gives you a quick visual indicator of how much structural activity has occurred.

7. Walkthrough

  1. Open the sample project or create a new one with at least one Functional Group.
  2. Add a new scenario — name it "Auth Tests".
  3. Add two tests: "Login" and "Register".
  4. Rename "Register" to "Signup".
  5. Click 📋 History on the Functional Group.
  6. You should see 4 entries: Add Scenario, Add Test (×2), Rename Test.
  7. Click the Test filter — only the 3 test-related entries show.
  8. Click the Scenario filter — only the 1 scenario entry shows.
  9. Delete one of the tests. Check history — a new "Delete Test" entry appears.
  10. Click All to see the complete log.
