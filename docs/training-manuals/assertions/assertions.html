1. What Are Assertion Presets?

Assertion Presets are reusable collections of validation rules that you can attach to any API request in RedfireForge. Instead of manually configuring assertions for every request, presets let you import a curated set of checks with a single click.

Each preset targets a specific testing concern — from basic health checks to full contract validation — and bundles the right assertion types, operators, and expected values together.

💡 Tip Think of assertion presets like test templates. They encode best-practice validation patterns so you can focus on what matters — testing your API — instead of manually wiring up checks.

2. How to Use Assertion Presets

  1. Open the Gallery → Assertions tab in RedfireForge.
  2. Browse available presets by category or difficulty level.
  3. Click Import Preset on the preset you want to use.
  4. Attach the imported preset to any request node in your workflow.
  5. Run the request — RedfireForge evaluates all assertions against the live response.
  6. Review results: green ✅ for pass, red ❌ for fail, with details for each rule.

4. Categories

api-validation

Presets focused on verifying that an API behaves according to its contract. Checks include status codes, response structure, field presence, and data types. This is the most common category and covers everything from quick smoke tests to full contract validation.

data-quality

Presets that validate the integrity and correctness of response data. These go beyond structural checks to ensure values are within expected ranges, prices are positive, counts are accurate, and business rules are enforced.

security

Presets that verify security-related response properties. These check token formats, expiry dates, authentication headers, and other security-sensitive fields to ensure your API's auth layer is working correctly.

5. Learning Path

We recommend working through the presets in order of increasing difficulty:

Start Here — Easy

  1. 💚 API Health Check — Learn the basics: status code checks and array validation. Only 2 assertions to understand.
  2. 📄 Paginated List Validation — Build on the basics with numeric comparisons and learn how to validate paginated responses.

Level Up — Medium

  1. 🔐 Token Expiry Guard — Introduce regex pattern matching and date-based assertions. Learn security-focused testing.
  2. 💰 E-commerce Price Guard — Combine numeric range checks with array validation for data quality assurance.

Master — Advanced

  1. 📝 Full API Contract — Put it all together with 5 assertions covering status, numeric, and regex checks for complete contract validation.
