Phase 2 Changes

1. Status Indicator Dot

Colored dot on top-right corner of every node showing current execution state: idle (gray), running (blue pulsing), pass (green), fail (red).

Before: No visible state on nodes
After: Dot + border color changes live

2. Result Badge with Timing

Clickable badge showing HTTP status code + response time after execution. Green for 2xx, red for errors.

Before: Plain text status only
After: ✓ 200 · 142ms

3. Animated Edge Flow

Connection lines animate with flowing dashes during execution, then change color to green (pass) or red (fail) path.

Before: Static gray lines
After: Blue dash flow → green/red result

4. Running Spinner

Animated spinner + "Running…" text on node footer while HTTP request is in-flight, replacing the static badge.

Before: Text-only "Running…"
After: ⟳ spinner animation

5. Edge Labels (Yes/No)

Condition branches show "Yes" (green) and "No" (red) labels on edges, so the flow is instantly readable.

Before: Unlabeled branches
After: Yes / No labels

6. Skipped Path Dimming

Branches not taken (e.g., the "No" path when condition is true) are dimmed with dashed lines and reduced opacity.

Before: All paths look the same
After: Untaken paths fade to 35% opacity
