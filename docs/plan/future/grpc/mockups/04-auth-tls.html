⚡ Compression
Per-call gRPC compression is negotiated via grpc-encoding request header and grpc-accept-encoding response header.
Effective headers
grpc-encoding: gzip
server responds with:
grpc-accept-encoding: gzip,identity
⚠ If the server does not support the requested algorithm it will return status UNIMPLEMENTED.

Express Proxy: All calls go through the local Node.js server which uses @grpc/grpc-js to make real HTTP/2 gRPC calls. Works on both web and desktop.

Tauri Native: Uses Rust tonic directly — true HTTP/2, lower overhead, better streaming. Desktop (Tauri) only.

gRPC-Web: For endpoints already exposed via Envoy grpc-web proxy. Uses browser fetch with application/grpc-web+proto framing.
