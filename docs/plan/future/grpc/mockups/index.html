Phase 1 · Core
Main Studio — Unary Calls
Service explorer tree, connection bar (TLS modal + Auth badge — Phase 4J), type-aware proto form, JSON/Metadata/Auth tabs (dual entry), response panel with body/headers/trailers/timing. Click TLS badge to open shared modal.
Connection Bar TLS Modal Auth Tab Env Variables Response Timing

Phase 2 · Streaming
All Streaming Call Types
All four gRPC call types in one view: Unary, Server Streaming (live message log), Client Streaming (pending queue + EOF button), Bidirectional (full-duplex chat log + compose bar). Stream status, cancellation, message cap.
Server Streaming Client Streaming Bidirectional In-flight Cancel Message Log
Open Mockup → 02-streaming.html
Phase 3 · Proto Management
Schema Sources & Browser
5 descriptor sources: Server Reflection (v1 + v1alpha), Proto Files with import-path resolver, Protoset binary, Buf Schema Registry, URL import. Schema browser with service/method/field docs. Well-known types. grpcurl copy button.
Server Reflection Proto Files Protoset Well-Known Types BSR
Open Mockup → 03-proto-management.html
Phase 4 · Security & Call Config
TLS, Auth & Call Settings
Connection Settings drawer (Phase 4J-C): TLS/mTLS tri-mode, auth type pills, call settings, compression, health, K8s port-forward, transport. TLS badge also opens shared modal (same as GraphQL/WebSocket). Links to mockup 01 for main studio context.
Settings Drawer TLS Modal Auth Pills K8s Port-Forward Compression Health Check
Open Mockup → 04-auth-tls.html
Phase 5 · Collections
Collections, History & Snapshots
Collection tree (by service/method), saved request detail with body + metadata, snapshot testing with diff view (Kreya-inspired), call history (47 entries, filterable), grpcurl import modal, grpcurl export. Run history & stats per saved request.
Collections Tree Snapshot Testing Diff View Call History grpcurl Import

Load Testing, Mock Server, Schema Diff, Stats
Load test runner (ghz-inspired): latency histogram, throughput chart, status donut, live metrics. gRPC mock server with rule editor (condition → response). Proto schema diff (breaking/non-breaking detection). Per-method RPC statistics table.

Competitive Differentiators Visualized
🛡
Full Auth Stack
Bearer, Basic, API Key, OAuth2, GCE/GCP ADC — no other open-source gRPC tool has all five. Mockup 04
☸
K8s Port-Forwarding
Warthog-inspired: auto kubectl port-forward with kubeconfig context selector. Unique among GUI gRPC clients. Mockup 04
📸
Snapshot Testing
Kreya-inspired: save response baseline, diff on each run, accept/reject changes. First open-source tool with this feature. Mockup 05
⏱
Per-call Deadline
Injects grpc-timeout header per gRPC spec §2.2.6 (DEADLINE_EXCEEDED = status 4). Shown in connection bar. Mockup 01 + 04
⚙
Workflow Integration
grpcUnary + grpcServerStream workflow nodes — no other tool (Postman, Insomnia, Kreya) has workflow automation. Phase 6
⚡
ghz-style Load Testing
Latency histogram, p50/p95/p99, throughput chart, status breakdown — all in a GUI. Only ghz (CLI) offers this currently. Mockup 06
