Recommended Option A — tab.auth override

Mirror endpoint/TLS: each tab can override auth. Badge shows active tab's resolved auth. Single-tab sessions still edit page default.

Option D Explicit inherit chain

Option A plus Requests-style inherit modes: inherit workspace, inherit global profile directly, or explicit override with reset.

Option B Connection profiles only

Auth isolation via named profiles per tab. Works today for linked tabs, but heavy UX when only auth differs.

No auth popover — users put Authorization in per-tab Headers. Duplicates UI; breaks subscription connectionParams.
