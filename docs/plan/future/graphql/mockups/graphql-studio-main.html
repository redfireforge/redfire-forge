Auto-detect note: /stream endpoints default to SSE

When Auto transport is selected and the endpoint URL ends with /stream or contains /stream?, the client automatically uses SSE (graphql-sse) instead of WebSocket. A → SSE hint badge appears inline next to the transport dropdown to signal the auto-selection. This matches common conventions (e.g. https://api.example.com/graphql/stream). For wss:// or non-stream URLs, Auto defaults to WebSocket (modern graphql-transport-ws). Also: wss:// URLs are auto-converted to https:// when SSE transport is used, so users can switch transport without changing the URL.

Filter mode rules:
  • Text mode: substring match across JSON.stringify(message.data)
  • JSONPath mode: path existence $.order.id or comparison $.order.status == "SHIPPED"
  • Note: the expression root is message.data (the GraphQL payload), so do not include a leading data. prefix
  • Supports ==, !=, >, >=, <, <= operators
  • Escape key closes the filter bar and resets filter state
  • Count shows Showing N/M — live, not a search-only state
