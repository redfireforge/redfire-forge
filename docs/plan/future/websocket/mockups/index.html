🔥 RedfireForge v0.6.0

WebSocket & SSE — Redesign Mockups

A proposed redesign that brings WebSocket & SSE into an Insomnia-style split-pane request editor, reusing the existing RedfireForge Requests design language. Every implemented feature is preserved — mapped into a cleaner information architecture. Each page below is a static, theme-aware mockup (toggle the theme in the top bar to verify it adapts).

Information Architecture

The legacy view tabs (Connect · Messages · Saved · Mock) become two things: a mode switch (Client / Mock Server / Saved) and a split-pane workspace where Connect config lives on the left and Messages/Events stream on the right — so you configure and watch traffic at the same time instead of switching tabs.
