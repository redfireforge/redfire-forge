Lesson Content — WebSocket Basics

Concept

📖 Understanding WebSocket

WebSocket provides full-duplex communication over a single TCP connection. Unlike HTTP request-response, both sides can send data at any time.

How it works:

  1. Client sends HTTP Upgrade request
  2. Server responds with 101 Switching Protocols
  3. Persistent connection established
  4. Both sides exchange frames freely

Key Terms: Frame · Handshake · Subprotocol · Event

Live Demo Steps

  1. Welcome to WebSocket Studio (highlight Client button)
  2. Enter a WebSocket URL (highlight URL input)
  3. Connect to the Server (highlight Connect button)
  4. Compose a Message (navigate to Compose tab)
  5. Send Your Message (highlight Send button)
  6. Monitor Live Events (switch to Events tab)
  7. Multiple Connections (highlight + tab button)
  8. Disconnect (highlight Disconnect button)

Lesson Content — Auth & Transport

Concept

📖 Authentication & Transport Modes

WebSocket auth is uniquely challenging because browsers cannot set custom HTTP headers on the WebSocket handshake.

Three Transport Modes:

  • Direct — browser-native, no custom headers possible
  • Proxy — backend relays headers on your behalf
  • Native — Tauri desktop, full header control

Rule: Header-based auth (Bearer, Basic, API-Key) → auto-switches to Proxy transport.

Live Demo Steps

  1. Open the Auth tab
  2. Choose auth type (type selector dropdown)
  3. Bearer token example (fill token field)
  4. Transport auto-switch callout (highlight info banner)
  5. Protocol selector on Connect tab
  6. TLS settings panel
  7. Transport badge on connection tab
