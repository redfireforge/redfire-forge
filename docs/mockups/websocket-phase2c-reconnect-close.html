RFC 6455 Close Codes Reference
1000 Normal Closure — connection fulfilled its purpose 1001 Going Away — endpoint shutting down (page navigation, server restart) 1002 Protocol Error — endpoint received a frame that violates the protocol 1003 Unsupported Data — received data type it cannot handle (e.g. text-only got binary) 1006 Abnormal Closure — no close frame received (network failure) 1008 Policy Violation — message violates server policy 1011 Internal Error — unexpected server condition 4000–4999 Application-defined — custom codes for your API
