4. User Flows
Save Flow:
User clicks Save → auto-creates version snapshot → "Workflow saved · Version 13 created" toast
Duplicate detection skips save if nothing changed since last version.
Restore Flow:
User clicks "↩ Restore" on v10 → confirm dialog: "Restore to version 10? Current unsaved changes will be lost." → replaces canvas state → persists → toast.
Compare Flow:
User checks 2 version checkboxes → "Compare Selected" button enables → opens diff modal with Nodes/Edges/Variables/Services tabs.
Undo Persistence:
Undo/redo stack saved to localStorage per workflow ID → survives page refresh. Currently lost on refresh (in-memory only, max 50).
5. Export/Import Integration
Export: ExportOptionsPopover gets a new checkbox: "☑ Workflow Versions (12)" — same pattern as Response/Rules versions.
Import: ImportVersionModal shows: "The imported file contains workflow version history. ☑ Include workflow versions (8)"
Settings: Version checkboxes added to Settings Export/Import tab for bulk operations.
