Changes summary

REMOVED from top toolbar:
• "Compare against run…" dropdown
• "Show Trend" toggle
• RunComparisonPanel appearing inline between toolbar and metrics
NEW ⚡ Analysis tab contains:
• Compare picker + RunComparisonPanel
• TrendChart (always in sidebar)
• Baselines list with Compare/Unmark/Rename
• Thresholds (collapsed by default, expand to edit)
REMOVED bottom tabs:
• "Request Details" (becomes top-level tab 2)
• "SLA Status" (becomes top-level tab 3)
• "★ Baselines" (absorbed into Analysis tab)
STAYS PERSISTENT (sticky header):
• Run type filter pills
• Run selector dropdown
• ★ Set Baseline toggle (always 1 click away)
• SLA status badge (visible at all times)
