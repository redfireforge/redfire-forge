💡
Key design decisions shown:
• Columns = only metrics that have at least one target configured (no empty columns). Empty cells show "—".
• Feature row = rollup dot — worst status across all scenarios under it. No new schema needed.
• Scenario row = evaluates its own SlaTarget.scenarioName match directly.
• Test rows = each individual request evaluated against the parent scenario's target. Shows which specific tests caused the failure.
• Hierarchy is independently expandable — click Feature to see scenarios, click Scenario to see individual tests.
