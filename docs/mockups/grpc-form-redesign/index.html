gRPC Complex Payload UX Directions

Three fundamentally different strategies for complex payload authoring. These are standalone research mockups and intentionally not wired into app logic.

Strategy A

Guided Cards + Progressive Disclosure

  • Field groups become compact cards with completion states.
  • Only active branch content stays expanded.
  • Great for onboarding and broad teams.
Open Mockup A
Strategy B

Schema Tree + Focus Editor

  • Left tree for navigation and status heatmap.
  • Right panel edits one selected node deeply.
  • Best for expert users and very deep schemas.
Open Mockup B
Strategy C

JSON-First + Visual Assist

  • Main editor is JSON for speed and copy/paste.
  • Inline assistants for oneof/map/repeated blocks.
  • Best for power users and automation-heavy flows.
Open Mockup C 
Research baseline: Insomnia tabbed request anatomy, Stoplight Elements 3-column interactive console,
JSONForms/RJSF schema-driven principles, common API-client split panes.

Objective: reduce cognitive load for complex message payloads while preserving speed for experts.
