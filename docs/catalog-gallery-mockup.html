User Flow
1. User clicks "+ Import Spec" in sidebar → Import modal opens
2. User clicks "Sample Gallery" tab → sees sample API cards with search + category filter
3. User clicks a card → same preview step as Upload/Paste (reuses existing preview UI)
4. User clicks "Import" → sample API appears in catalog sidebar, fully browsable

Implementation:
• Data: src/data/sampleCatalogSpecs.ts — array of { id, name, description, icon, category, specYaml }
• UI: 3rd tab in CatalogImportModal.tsx — card grid with search + pills
• On select: calls parseOpenApiSpec(entry.specYaml) → jumps to existing preview step
• No new modal, no new routes — plugs into existing import flow
