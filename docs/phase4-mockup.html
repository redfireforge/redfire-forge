Phase 4 Scope

  • Config panel tabs — 4 tabs (Config, Input, Output, Logs). Output shows last execution status/body/extractions. Logs shows step-level timeline.
  • Palette search — Real-time filter with highlight. Hides non-matching blocks and auto-expands matching categories.
  • Collapsible sections — Request, Auth, Extractions, Assertions, Variables become collapsible with chevron + count badges.
  • SVG toolbar icons — Replace 🔗 📋 🔍 ▶ with Lucide-style SVG icons. Consistent sizing and alignment.
