4. Undo / Redo New

Canvas operations (add/delete/move nodes, add/delete edges, node config changes) are tracked in an undo stack. ⌘Z to undo, ⌘⇧Z to redo. Buttons also added to the floating pill controls bar. Max 50 undo levels.

6. Node Copy / Paste / Duplicate Before → After

Select a node and press ⌘C to copy, ⌘V to paste (offset +40px), or ⌘D to duplicate in-place. Copies include the full node config (HTTP settings, variables, extractions). A brief copy indicator appears on the node. Also available via the right-click context menu.

Key Principles
✦ Zero new dependencies — keyboard listeners via useEffect
✦ Toast system uses React Context + portal — no library
✦ Command palette built from existing action handlers
✦ Undo stack stores node/edge snapshots (max 50 entries)
✦ Copy/paste serializes node data to clipboard as JSON
✦ All shortcuts use ⌘ (Mac) / Ctrl (Windows/Linux)
✦ Focus trap: shortcuts only fire when canvas area is focused
✦ All E2E selectors preserved — additive changes only
