2. Step Execution Timeline New

A vertical timeline in the Console panel showing each step's execution in order — with status dots, HTTP codes, durations, and extracted variable counts. Replaces raw log lines with a structured, scannable view.

4. Enhanced Edge Flow Animation Before → After

Edges between nodes animate with marching dashes when data is flowing, turn green on pass, red on fail, and dim when skipped. Creates a visual "data flow" effect that makes execution order obvious at a glance.
